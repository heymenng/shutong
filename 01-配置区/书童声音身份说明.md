# 书童声音身份说明

> 本文档用于固定书童的“声音身份”，防止在不同运行环境中误用系统测试音或其他音色。

---

## 一、书童的常规声音

| 项目 | 设定 |
|---|---|
| 语音后端 | `xfyun_oral`（讯飞超拟人语音） |
| 音色名称 | `x6_tianjingshaonv_pro` |
| 音色昵称 | 天津少女 |
| 使用对象 | 师父、家长、孩子 |
| 使用场景 | 日常语音对话、回复、问候、提醒 |

这是书童与师父交流的**默认声音**。任何自动或手动的语音回复，都应优先使用该音色。

---

## 二、禁止事项

1. **禁止把 macOS `say` / `Tingting` 作为默认声音或“系统测试音”使用。**
2. **禁止在师父在场时，未经确认切换到其他音色。**
3. 只有在以下情况才允许临时回退：
   - 讯飞密钥未配置或已失效
   - 网络无法连接讯飞服务器
   - 明确收到师父指令要求切换

---

## 三、回退策略（优先级）

当讯飞超拟人语音不可用时，按以下顺序回退：

1. `xfyun_oral`（天津少女）—— 首选
2. `edge-tts`（微软 Edge 在线 TTS）—— 临时回退
3. `say` / `pyttsx3` —— **仅当师父显式配置 `voice_backend: say` 时才允许使用**

---

## 四、配置文件位置

### 代码默认配置

- 文件：`03-引擎区/书童程序/核心/配置.py`
- 关键项：
  ```python
  "voice_backend": "xfyun_oral",
  "voice_name": "x6_tianjingshaonv_pro",
  ```

### 运行时密钥

- 文件：`01-配置区/.env`
- 关键项：
  ```env
  XFYUN_APP_ID=xxx
  XFYUN_API_KEY=xxx
  XFYUN_API_SECRET=xxx
  ```

> `.env` 已加入 `.gitignore`，不会提交到仓库。
