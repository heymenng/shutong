# 伴读书童AI · 家庭版安装说明

## 这是什么？

伴读书童AI 家庭版，是一个运行在您本地电脑上的智慧家庭助手。

- **本地保存**：您家庭的档案、对话记录、陪伴计划、头像等隐私数据，全部存在您自己的电脑里。
- **云端智慧**：书童的灵魂、核心规则、推理能力来自云端服务，需要购买订阅后使用。
- **长期陪伴**：从孩子 0 岁陪伴到 18 岁，甚至更长。
- **全家可用**：不只是陪孩子，家长也能用。书童陪孩子学习成长，墨童帮家长写文案、整资料、记家庭周报。

## 安装前准备

1. 一台 Windows 或 Mac 电脑
2. 已安装 Python 3.9 或更高版本（如未安装，请访问 python.org 下载）
3. 由师父或管理员分配的 `family_id` 和订阅密钥

## 安装步骤

### Mac 用户

1. 双击运行 `install.py`
2. 等待安装完成（会自动创建虚拟环境、安装依赖）
3. 打开 `config.json`，填入您的 `family_id` 和订阅密钥
4. 以后每次使用，双击 `启动书童.command`

### Windows 用户

1. 双击运行 `install.py`
2. 等待安装完成
3. 打开 `config.json`，填入您的 `family_id` 和订阅密钥
4. 以后每次使用，双击 `启动书童.bat`

## 配置说明

打开 `config.json` 文件，修改以下字段：

```json
{
  "cloud_api_base": "https://your-cloud-server.example.com",
  "family_id": "您的家庭ID",
  "api_key": "您的订阅密钥"
}
```

- `cloud_api_base`：云端服务地址（由师父或管理员提供）
- `family_id`：您的家庭标识
- `api_key`：订阅密钥，一家庭一钥

## 家长也能用：墨童

书童有两个分身：

- **书童**：陪孩子聊天、讲故事、辅导作业、守护成长。
- **墨童**：帮家长写朋友圈文案、给老师的信、家庭周报、育儿心得、工作总结。

打开家庭端后，在左侧找到 **🦞 墨童 · 家长助手**，点击即可使用。生成的内容会自动保存到您家庭的文件夹里，随时查看和修改。

## 注意事项

- 安装包中**不包含**书童的灵魂文件（AGENTS.md、核心提示词等），仅包含客户端与本地数据存储。
- 首次运行前必须正确填写 `config.json`，否则无法连接云端服务。
- 如果更换电脑，只需拷贝整个安装目录，重新运行 `install.py` 即可。
