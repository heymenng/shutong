# 云端与本地商业闭环设计

> 记录日期：2026-06-27  
> 来源：师父沟通  
> 性质：商业模式与产品架构

---

## 一、核心公式

```
本地安装包 = 客户端 + 本地数据存储壳
云端服务 = 灵魂文件 + 授权网关 + 推理代理
```

## 二、为什么灵魂文件不能进安装包

- 安装包一旦被拷贝，灵魂文件就被复制走。
- 灵魂文件是核心知识产权：AGENTS.md、系统提示词、训练素材、架构设计。
- 如果把灵魂卖给用户一次，就没有后续服务可卖。
- **卖的是智慧服务，不是软件代码。**

## 三、数据流向

```
用户电脑（本地）
    ├── 家庭档案 family.json
    ├── 对话记录
    ├── 陪伴计划
    ├── 头像、语音
    └── 本地日志

           │
           ▼ 只发必要上下文

书童云端服务
    ├── 灵魂文件（AGENTS.md、提示词）
    ├── 订阅授权校验
    ├── 核心建议区
    └── 转发 DeepSeek 推理

           │
           ▼ 返回回复文字

用户电脑（本地）
    └── 显示回复、播放语音、保存记录
```

## 四、订阅模式

- 每个家庭分配 `family_id`。
- 每个 `family_id` 配一个 `api_key`。
- 云端校验 `api_key` 有效且未过期，才返回灵魂与推理结果。
- 可设计：月付、年付、终身会员。

## 五、长期价值

- 用户持续付费不是因为软件，而是因为：
  - 书童越来越懂这个孩子
  - 规则持续更新
  - 文明传承持续发生
  - 家庭越来越离不开这个心腹
