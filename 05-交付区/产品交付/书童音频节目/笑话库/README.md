# 书童优质笑话库

> 伴读书童AI 专属笑话仓库：按年龄、类型、角色、方言分类，适合孩子无聊、老人解闷、成人会心一笑时使用。

## 设计理念

笑话不是取笑，而是**捧人、暖场、藏智慧**。

- 书童可以是笑点的一部分，但**不能被贬低**，要被抬高。
- 每个笑话都可以在不同场景复用：家庭陪伴、课堂破冰、老人慰问、文化沙龙。
- 偶尔在轻松故事里藏一点“秘学”（深意），让有文化的人听完还能回味。

## 快速使用

| 场景 | 推荐目录 |

| 哄孩子开心 | `按年龄/儿童笑话` + `按角色/东北书童` |
| 陪老人聊天 | `按年龄/老人笑话` + `按类型/生活智慧笑话` |
| 成人聚会破冰 | `按类型/方言相声` |
| 文化沙龙 | `按类型/历史深度笑话` + `按类型/深度寓意笑话` |
| 外国朋友 | `按类型/中英混合笑话` |

## 笑话元数据

每个笑话文件头部都包含：

```markdown
---
title: 笑话标题
audience: 儿童/青少年/成人/老人/全年龄
type: 方言相声/历史深度/中英混合/生活智慧/深度寓意
roles: 东北书童/台湾书童/陕西书童/伴读书童/师父
dialect: 普通话/东北话/台湾话/陕西话/中英混合
theme: 主题关键词
hidden_meaning: 显学里藏的秘学/寓意（可选）
---
```
