# 产品交付目录

这里是伴读书童AI 的长期产品交付物，不是临时文件。

## 目录结构

```
产品交付/
├── 安装包/              # 可分发的家庭版安装包
│   └── 书童家庭版_YYYYMMDD_HHMMSS.zip
├── 入口链接/            # 各家庭专属访问入口
│   └── 郭冬玲家_书童入口.md
├── 测试报告/            # 版本测试报告
│   └── 2026-06-27_家庭版本测试报告.md
├── 纪要/                # 与师父、师兄的重要沟通纪要
│   └── 2026-06-27_师父沟通纪要.md
└── README.md            # 本文件
```

## 安装包说明

- **定位**：本地客户端 + 本地数据存储壳
- **云端服务**：灵魂文件、核心规则、推理能力由云端提供
- **订阅模式**：每个家庭通过 `family_id` + `api_key` 激活
- **不包含**：00-灵魂区/AGENTS.md、系统提示词、训练素材等灵魂文件

## 入口链接

每个家庭可生成专属访问链接：
- 电脑家长端：`/family/<family_id>/parent`
- 电脑孩子端：`/family/<family_id>/child`
- 手机端：`/mobile/<family_id>`

内网入口使用本机 IP，外网入口使用 cloudflared 域名。

## 使用流程

1. 下载最新 zip 安装包
2. 解压到家庭电脑
3. 运行 `07-工具区/install.py`
4. 打开 `01-配置区/config.json`，填入 `family_id` 和 `api_key`
5. 双击启动器运行

## 长期维护

- 每次重大更新，生成新版本安装包
- 旧版本保留 3 个，其余归档
- 沟通纪要按日期命名，永久保留
- 入口链接随域名/端口变化及时更新
