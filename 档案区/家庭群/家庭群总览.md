## 新增家庭步骤

1. 在 `档案区/家庭群/` 下选择合适的分类目录（没有就新建）
2. 新建 `<family_id>/family.json`
3. 在该家庭目录下新建 `孩子档案/` 目录，放入孩子的 `*档案*.json` 文件
4. 可选：在该家庭目录下新建 `陪伴计划/`、`学习计划/`、`孩子作品/` 等子目录
5. 运行同步脚本：
   ```bash
   .venv/bin/python 脚本/同步家庭群到运行时.py
   ```
6. 重启书童服务
