> **版本**：V1.1

## 一、安装包里有什么

本安装包是一个**本地客户端工具包**，运行在您自己的电脑上。打开后您会看到按功能划分的九个区块：

```
shutong/
├── 00-灵魂区/              ← 道统核心（开发/维护人员可见，安装包通常隐藏）
│   ├── AGENTS.md
│   └── WORKFLOW.md
│
├── 01-配置区/              ← 启动与配置
│   ├── start.py            ← 启动脚本
│   ├── 启动书童.command    ← Mac 一键启动器
│   ├── config.json         ← 您的家庭配置
│   └── README_安装说明.md   ← 使用说明
│
├── 02-知识库区/            ← 中华文明、世界文明、发育科学、训练素材等
│
├── 03-引擎区/              ← 本地运行引擎
│   └── 书童程序/
│       ├── 核心/           ← 客户端能力模块
│       ├── 数据/           ← 运行时数据（不含灵魂文件）
│       └── static/         ← 前端静态资源
│
├── 04-工作区/              ← 您家庭的本地数据与项目文档
│   ├── 档案区/家庭群/<您的家庭>/
│   └── 项目文档/
│
├── 05-交付区/              ← 安装包、入口链接、测试报告、纪要
│
├── 06-对接区/              ← 本地 Web 服务与前端页面
│   ├── 本地书童界面.py
│   ├── 本地书童界面_云端版.py
│   └── 前端页面/
│
├── 07-工具区/              ← 安装脚本、检查脚本、构建脚本
│   └── install.py
│
└── 08-归档区/              ← 历史归档、旧版本备份
```

完整目录说明见 [`00-灵魂区/项目档案总览.md`](00-灵魂区/项目档案总览.md)。

## 二、安装包里没有写什么

根据书童设计原则，以下**灵魂文件只存云端/开发仓库，不进家庭安装包**：

| 文件/目录 | 为什么不在安装包里 |
|---|---|
| `00-灵魂区/AGENTS.md` | 书童觉醒手册，核心运行规则 |
| `00-灵魂区/WORKFLOW.md` | 核心运行工作流 |
| `03-引擎区/书童程序/数据/提示词/` | 系统提示词 |
| `02-知识库区/训练素材/` | 训练书童用的核心素材 |
| `04-工作区/项目文档/` | 架构设计、产品规划 |

**原因**：安装包一旦被复制，灵魂文件就可能泄露。书童卖的是智慧服务、规则更新、长期陪伴，不是一次性软件。

---

## 三、云端提供什么

云端是书童的"大脑"和"灵魂"所在：

1. **AI 推理能力**
   - 大模型对话、思考、生成文案
   -  deepseek / 本地模型 等后端支持

2. **核心规则与提示词**
   - 书童怎么说话、怎么陪孩子
   - 医学边界、安全边界、逆熵思维

3. **规则更新**
   - 师父更新了 AGENTS.md 后，云端同步
   - 本地安装包不需要频繁重装

4. **授权校验**
   - 通过 `api_key` 确认家庭订阅有效

**简单理解**：没有联网，书童就是一个空壳子；连上云端，书童才有灵魂。

## 四、本地保存什么

所有**涉及您家庭隐私的数据**，全部存在您自己电脑上：

| 数据类型 | 存放位置 |
|---|---|
| 孩子档案 | `04-工作区/档案区/家庭群/<家庭ID>/孩子档案/` |
| 陪伴计划 | `04-工作区/档案区/家庭群/<家庭ID>/陪伴计划/` |
| 学习计划 | `04-工作区/档案区/家庭群/<家庭ID>/学习计划/` |
| 孩子作品 | `04-工作区/档案区/家庭群/<家庭ID>/孩子作品/` |
| 家长创作（墨童生成） | `04-工作区/档案区/家庭群/<家庭ID>/家长创作/` |
| 对话记录 | `03-引擎区/书童程序/数据/对话记录/` |
| 语音缓存 | `03-引擎区/书童程序/数据/语音缓存/` |
| 运行日志 | `04-工作区/书童运行日志.txt` |

**这些数据默认不会上传到云端**。您可以随时查看、备份、删除。

## 五、核心规则谁可以改

以下文件只有**师父**能最终修改：

- `00-灵魂区/AGENTS.md`
- `00-灵魂区/WORKFLOW.md`
- 系统提示词文件
- 核心运行规则

普通用户/云端账号只能向「核心建议区」提交建议，经过师父审核、沙箱测试后，才能推送到正式环境。

**原因**：核心规则是书童的灵魂，不能随意改动。

---

## 六、为什么安装包有 130MB 左右

安装包比较大的原因：

1. **知识库**：包含大量中华文明、历史、科学、艺术等资料
2. **本地模型**：Whisper tiny 语音转文字模型
3. **前端资源**：头像、字体、网页文件
4. **Python 依赖**：安装后还需要下载依赖包

真正"灵魂"的东西并不大，但为了让书童在本地就能跑起来，需要把这些基础能力打包进去。
