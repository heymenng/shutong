# 伴读书童AI · 家庭安装包说明

## 安装包定位

家庭安装包 = 本地客户端 + 本地数据存储壳 + 云端智慧服务。

- **本地客户端**：统一的 HTML、JS、CSS、后端服务界面
- **本地数据**：每个家庭只改 `书童程序/数据/家庭/<family_id>/family.json`
- **云端智慧**：书童的灵魂文件（AGENTS.md、系统提示词、核心规则）只存云端，安装包中不包含
- **新增家庭**：复制公共版本 → 修改 `family.json` + `config.json` → 完成

## 运行原理

```
┌─────────────────┐         ┌─────────────────┐         ┌─────────────────┐
│  客户本地电脑    │  ───▶   │   书童云端服务   │  ───▶   │  云端 DeepSeek   │
│  （安装包）      │ 发请求   │ （灵魂+授权网关） │ 发推理   │  （核心推理）     │
└─────────────────┘         └─────────────────┘         └─────────────────┘
        │
        ▼ 本地存储
   书童程序/数据/家庭/
   书童程序/数据/对话记录/
   档案区/陪伴计划/
```

- **本地**：保存家庭档案、对话记录、陪伴计划、头像、日志
- **云端书童服务**：保存灵魂文件、校验订阅密钥、转发必要上下文到 DeepSeek
- **云端 DeepSeek**：只处理单次推理请求，返回回复文字

## 安装步骤

### Mac 用户

1. 确保电脑已安装 Python 3.9+（未安装可到 python.org 下载）
2. 双击运行 `install.py`
3. 等待安装完成
4. 打开 `config.json`，填入 `cloud_api_base`、`family_id`、`api_key`
5. 以后每次使用，双击 `启动书童.command`

### Windows 用户

1. 确保电脑已安装 Python 3.9+（未安装可到 python.org 下载）
2. 双击运行 `install.py`
3. 等待安装完成
4. 打开 `config.json`，填入 `cloud_api_base`、`family_id`、`api_key`
5. 以后每次使用，双击 `启动书童.bat`

## 文件说明

| 文件 | 作用 |
|---|---|
| `install.py` | 自动安装虚拟环境、依赖、生成配置文件 |
| `start.py` | 启动本地服务并打开浏览器 |
| `config.json.template` | 配置文件模板 |
| `config.json` | 安装后生成的家庭订阅配置 |
| `README_安装说明.md` | 家庭用户安装说明 |
| `manifest.json` | 安装包元数据（版本、类型、不含灵魂文件声明） |
| `启动书童.command` | Mac 一键启动器 |
| `启动书童.bat` | Windows 一键启动器 |
| `本地书童界面.py` | 本地后端服务 |
| `书童家庭端.html` | 电脑端页面 |
| `书童手机端.html` | 手机端页面 |
| `书童程序/数据/家庭/<family_id>/family.json` | 家庭数据 |

## 多家庭配置

新增家庭时，复制一份 `书童程序/数据/家庭/default_family/family.json`：

```bash
书童程序/数据/家庭/
├── default_family/        # 师父家
├── family_guodongling/    # 郭冬玲家
├── family_lanxin/         # 蓝心老师家
└── family_dabo/           # 大伯家（新建）
```

每个家庭访问自己的入口：

- 电脑家长端：`http://127.0.0.1:3876/family/<family_id>/parent`
- 电脑孩子端：`http://127.0.0.1:3876/family/<family_id>/child`
- 手机端：`http://127.0.0.1:3876/mobile/<family_id>`

## 隐私说明

- 所有家庭私有数据只保存在客户本地电脑
- 只有单次聊天请求中的必要上下文会发送到 DeepSeek 云端
- DeepSeek 不保存、不学习家庭数据
- 对话记录本地落盘，方便审计和回查
