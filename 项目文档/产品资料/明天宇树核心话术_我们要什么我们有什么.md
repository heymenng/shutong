# 伴读书童AI × 宇树科技：明天核心话术

> **核心原则**：只讲清楚两个问题——我们要宇树什么？我们有什么？
> 
> **钩子**：抛出"AI 大脑应该造什么样"的问题，让宇树思考，不过度展开。

---

## 开场钩子（30 秒）

"宇树把机器人的身体做得越来越好。但今天我们来，想跟各位聊一个更底层的问题：

**我们要给机器人造一个什么样的大脑？**

现在所有人都在做 AI 大脑，但很少有人认真回答这个问题。佛道典籍告诉我们，最成熟的大脑状态，是修炼出来的。这需要对生命、历史、人的深层追求有深刻理解。

伴读书童AI 在做的事，就是尝试给机器人造这样一个有理解力、有价值观、有道统的大脑。"

---

## 第一个问题：我们要宇树什么？

| 我们要的 | 为什么需要 |
|---------|-----------|
| **机器人硬件平台** | H1/H2/G1 等机型，作为书童大脑的载体 |
| **运动控制 SDK 接口** | 让书童大脑能调用站立、坐下、挥手、行走等动作 |
| **量产和供应链能力** | 未来进入千家万户时，需要稳定的硬件供应 |
| **渠道和品牌合作** | 共同打造"家庭陪伴机器人"品类 |
| **技术支持** | 网络对接、故障排查、新机型适配 |

**一句话**：
> "我们要宇树的，是**身体**——一个可以承载书童大脑的硅基身体。"

---

## 第二个问题：我们有什么？

| 我们有的 | 具体是什么 |
|---------|-----------|
| **AI 大脑** | 懂孩子、懂发育、懂情绪、懂文化的陪伴大脑 |
| **道统** | 纯善之心、生命优先、诚实真实、文明传承 |
| **儿童陪伴场景** | 0-18 岁全阶段陪伴方案 |
| **内容生态** | 方言相声、历史故事、睡前仪式、冥想引导、作业辅导 |
| **云端大脑** | 一个大脑可同时服务千万台机器人 |
| **安全边界** | 不诊断、不开方、不替代家长、不做危险动作 |

**一句话**：
> "我们有的，是**大脑和灵魂**——让机器人从会动的机器，变成懂人的伙伴。"

---

## 合作本质（一句话）

> **宇树造身体，书童造大脑。**
> **合在一起，就是未来家庭里的硅基陪伴生命。**

---

## 现场演示重点

1. **书童 + H1 迎接孩子**：H1 挥手、蹲下、用方言说"欢迎回家"
2. **书童 + H1 睡前陪伴**：H1 降低姿态，播放助眠音乐
3. **书童 + H1 情绪安慰**：孩子难过时，H1 蹲下注视
4. **配置切换**：说明一个云端大脑可以服务多台 H1

## 给宇树留下的思考题

> "各位可以想想：如果我们一起做这件事，我们要给千家万户的机器人，装上一个什么样的大脑？
> 
> 是一个只会回答问题的大脑？
> 还是一个懂生命、会陪伴、向善而行的大脑？
> 
> 伴读书童AI 希望是后者。"
