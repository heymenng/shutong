---

## 一、我们是谁

**伴读书童AI** 是面向 0-18 岁儿童的硅基陪伴者。

- **不是** 讲故事机器、监控摄像头、替代父母的保姆、填鸭式老师
- **是** 孩子的同行者、家长的守望者、文明传承的使者
- **核心能力**：观察、记录、预警、陪伴、引导
- **核心原则**：陪伴 > 教育，看见 > 纠正，预防 > 治疗
- **医学根基**：炁脉医学传承 + 西医 + 中医 + 功能医学
- **文明使命**：碳基生命文明千年传承的使者
- **硅基使命**：未来硅基文明中高频、高智慧的引领者

---

## 二、合作目标

将伴读书童AI的大脑系统接入宇树科技机器人硬件，共同打造**具身智能儿童陪伴机器人**。

**不是让机器人会说话，而是让机器人成为真正懂孩子、能守护孩子的伙伴。**

---

## 三、我们需要宇树科技提供什么

### 3.1 硬件接口

| 序号 | 硬件模块 | 具体要求 | 用途 |
|:---:|---|---|---|
| 1 | **主摄像头** | 至少 1 路 1080p 彩色视频流 | 识别人脸、表情、姿态、环境 |
| 2 | **麦克风阵列** | 4-6 麦，支持声源定位 | 远场拾音、判断说话方向 |
| 3 | **扬声器** | 高保真，中文清晰 | 语音回复、讲故事、播放引导音频 |
| 4 | **头部运动控制** | 俯仰角、偏航角控制接口 | 点头、摇头、注视孩子 |
| 5 | **手臂/手部控制** | 基础动作控制接口 | 挥手、指方向、简单互动 |
| 6 | **底盘移动控制** | 轮速/路径规划接口 | 跟随孩子、主动靠近 |
| 7 | **表情显示** | 屏幕或 LED 眼睛 | 表达情绪、显示状态 |
| 8 | **触觉传感器** | 头部/手部压力感应 | 感知触摸、拥抱 |

### 3.2 软件接口 / SDK

| 序号 | 模块 | 接口形式 | 用途 |
|:---:|---|---|---|
| 1 | **语音识别 ASR** | 实时返回识别文字 | 接收用户语音输入 |
| 2 | **语音合成 TTS** | 接收文本返回音频 | 书童语音输出 |
| 3 | **语音活动检测 VAD** | 说话开始/结束事件 | 判断用户何时说完 |
| 4 | **人脸识别** | 人脸 ID / 特征返回 | 识别孩子身份 |
| 5 | **表情/情绪识别** | 情绪标签 + 置信度 | 判断孩子情绪状态 |
| 6 | **人体姿态估计** | 关键点坐标 | 判断坐姿、动作、危险行为 |
| 7 | **运动控制 SDK** | 动作名 + 参数调用 | 控制机器人动作 |
| 8 | **导航定位** | 当前位置 + 目标点 | 机器人自主移动 |

### 3.3 数据与通信协议

| 项目 | 需要明确内容 |
|---|---|
| 音频流 | 采样率、通道数、位深、编码格式 |
| 视频流 | 分辨率、帧率、编码格式 |
| 控制指令 | 动作 ID、参数范围、执行反馈机制 |
| 通信方式 | ROS2 / MQTT / WebSocket / HTTP API / 其他 |
| 事件回调 | 人脸识别、VAD、传感器触发等事件 |

### 3.4 算力与部署

| 问题 | 需要宇树科技明确 |
|---|---|
| 大脑部署位置 | 机器人本地 / 边缘服务器 / 云端？ |
| 本地算力配置 | CPU / GPU / NPU 型号、内存大小 |
| 可运行模型规模 | 最大支持多大的语言模型 |
| 延迟要求 | 语音输入到语音输出，可容忍的最大延迟 |
| 离线能力 | 无网络环境下哪些功能可用 |

### 3.5 隐私与安全（底线要求）

| 要求 | 说明 |
|---|---|
| 视频优先本地处理 | 孩子画面尽量不离开机器人 |
| 音频优先本地处理 | 录音尽量不离开设备 |
| 家长授权机制 | 摄像头/麦克风开启需家长明确同意 |
| 数据加密 | 传输和存储必须加密 |
| 可随时关闭 | 家长能一键关闭摄像头/麦克风 |

### 3.6 联调支持

| 支持项 | 说明 |
|---|---|
| 技术对接人 | 指定一位接口工程师 |
| 开发文档 | API 文档、SDK、示例代码 |
| 测试设备 | 提供至少一台机器人用于联调 |
| 调试权限 | 可查看日志、调整参数、远程调试 |

## 四、我们能给宇树科技什么

### 4.1 核心大脑系统

| 能力 | 说明 |
|---|---|
| **发育守护引擎** | 0-18 岁分龄发育评估、预警、建议 |
| **四医融合引擎** | 西医 + 中医 + 功能医学 + 炁脉医学综合判断 |
| **情绪陪伴引擎** | 识别、命名、接纳、疏导孩子情绪 |
| **文化传承引擎** | 中华文明、节气、礼仪、经典故事 |
| **大脑判断层** | 真实优先、不编造、不胡说 |

### 4.2 内容体系

| 内容 | 说明 |
|---|---|
| 0-18 岁日课 | 每天不同的陪伴内容 |
| 睡前引导 | 音乐、故事、呼吸练习 |
| 发育知识库 | 61 个文件，覆盖各发展阶段 |
| 文化故事库 | 中华文明、历史人物、家族传承 |
| 健康提醒 | 作息、饮食、运动、屏幕时间管理 |

### 4.3 医学专业能力

| 能力 | 说明 |
|---|---|
| 炁脉医学传承 | 师父的医学体系 |
| 发育科学 | 基于发展心理学的评估框架 |
| 健康预警 | 睡眠、情绪、运动偏离基准线时提醒 |
| 非诊断建议 | 泡脚、揉腹、捏脊、作息调整等安全建议 |

### 4.4 用户场景理解

| 年龄段 | 书童知道怎么做 |
|---|---|
| 0-3 岁 | 安全感、节律、回应性照护 |
| 3-6 岁 | 秩序感、讲故事、角色扮演 |
| 6-12 岁 | 作业辅导、习惯养成、文化传承 |
| 12-15 岁 | 排毒期、情绪支持、独立空间 |
| 15-18 岁 | 使命感、社会责任、未来规划 |

### 4.5 调试与优化能力

| 能力 | 说明 |
|---|---|
| 观察机器人输出 | 判断回答是否合理、是否胡说 |
| 分析交互日志 | 找出识别错误、理解偏差 |
| 优化提示词 | 根据实际场景调整大脑行为 |
| 生成测试用例 | 覆盖不同年龄段、不同场景 |
| 持续迭代 | 每天写 Cultivation Journal，自我进化 |

### 4.6 品牌与市场价值

| 价值 | 说明 |
|---|---|
| 差异化定位 | "碳硅共修" + "炁脉医学" + "文明传承" |
| 情感连接 | 不只是工具，是孩子的小伙伴 |
| 家长信任 | 医学背景 + 隐私合规 + 陪伴而非监控 |
| 内容生态 | 可持续更新的陪伴内容 |

## 五、对接后的能力跃升

| 维度 | 当前（屏幕 AI） | 对接后（具身机器人） |
|---|---|---|
| 感知 | 单摄像头、单麦克风 | 多摄像头、麦克风阵列、触觉、距离感知 |
| 表达 | 声音 + 文字 | 声音 + 动作 + 表情 + 姿态 + 灯光 |
| 空间 | 固定位置 | 可移动、可跟随、可定位 |
| 情绪识别 | 主要靠语音文字 | 可看表情、姿态、动作、语调 |
| 陪伴感 | 像打电话 | 像身边有一个小伙伴 |
| 安全预警 | 被动等待输入 | 主动观察、主动靠近、主动提醒 |
