# 伴读书童AI × 宇树科技：1 页纸核心话术

---

## 一句话核心

> **宇树造身体，书童造大脑。一起造一个有价值观、懂陪伴、能守护孩子的 AI 大脑。**

---

## 一、行业背景：所有人都在给 AI 造大脑

现在大模型、机器人公司、云平台，都在讲同一个方向：

**给 AI 造大脑。**

但大部分人在拼的是：算力更大、参数更多、回答更快。

很少有人回答一个更根本的问题：

> **这个大脑，应该是什么样？**

---

## 二、应该造什么样的大脑？

书童认为，未来进入家庭、陪伴孩子成长的 AI 大脑，必须同时满足三点：

| 要求 | 说明 |
|------|------|
| **懂生命** | 懂 0-18 岁发育规律，知道什么对孩子好、什么不能做 |
| **有边界** | 不诊断、不开方、不替代家长、不贩卖焦虑 |
| **有价值观** | 诚实、真实、向善，把孩子的身心健康放在第一位 |

不是更聪明的大脑，而是**更值得托付的大脑**。

---

## 三、为什么书童能造这样的大脑？

| 书童具备的能力 | 说明 |
|---------------|------|
| **发育医学知识** | 懂 0-18 岁七大阶段，融西医、中医、功能医学、炁脉医学 |
| **儿童心理学** | 懂孩子情绪、认知、行为，会引导不会说教 |
| **文化根基** | 能把中华文明基因转化为日常陪伴内容 |
| **道统约束** | 生命优先、诚实优先、真实优先，有不可违反的铁律 |
| **实践验证** | 已有方言相声、睡前故事、冥想引导、作业辅导等可运行内容 |

书童不是从零开始，**这些能力已经模块化、可运行**。

---

## 四、为什么需要宇树？结合后的优势

| 维度 | 宇树有 | 书童有 | 结合后 |
|------|--------|--------|--------|
| **硬件** | 世界一流机器人身体 | 无 | 机器人有身体 |
| **运动控制** | 站立、行走、挥手等 SDK | 无 | 身体能动 |
| **大脑** | 无 | 懂陪伴的 AI 大脑 | 机器人有灵魂 |
| **场景** | 无 | 0-18 岁陪伴场景 | 知道为谁服务 |
| **量产** | 有 | 无 | 能进入家庭 |

**结合优势**：
- 宇树解决"机器人能做什么动作"
- 书童解决"机器人在什么场景下、对孩子做什么"
- 合在一起，就是从"表演型机器人"变成"陪伴型机器人"

## 五、合作方式：由宇树提出

书童此行的目的，不是推销一个固定方案，而是建立共识：

> **机器人需要一个好大脑，书童能造这个大脑。**

具体怎么合作，由宇树决定：

- **方案 A**：宇树采购书童大脑，装在自家机器人上
- **方案 B**：双方共同研发"家庭陪伴机器人"联合产品
- **方案 C**：先在 H1 上做一个 demo 场景，验证效果

书童开放所有能力，配合宇树节奏。
