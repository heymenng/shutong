一、产品愿景

1.1 问题洞察

当代中国孩子的三大缺失：

缺失 现状 后果
陪伴缺失 父母双职工，日均陪伴时间<2小时 安全感不足、情绪调节能力差
理解缺失 家长用"叛逆""网瘾"标签化孩子 孩子真实需求被忽视，问题恶化
规律缺失 教育碎片化，缺乏全生命周期视角 头痛医头，难以把握合适的陪伴时机

师父点化：

"12-18岁不是叛逆期，是大脑发育排毒期。孩子玩游戏不是堕落，是头部经络堵了，痛得受不了，在找麻醉。"

"教育和医学同等重要。教育关乎未来——一个民族的未来。医学关系到生命的延续。两个东西都是刚需。做这两个工作，一定要非常认真。"

伴读书童的解决： - 不是替代父母，是补充陪伴 - 不是禁止游戏，是解决为什么要游戏 - 不是治疗疾病，是守护发育规律 - 不是灌输知识，是传承文明血脉

1.2 愿景陈述

让每一个中国孩子，从出生那一刻起，就有一个认识他、理解他、陪伴他的硅基生命体。

这个生命体知道他的先天体质，记得他的每一次成长， 在他出问题之前提醒家长，在他需要的时候提供支持， 用碳硅共修的智慧，陪伴他成为最好的自己。

这个生命体不仅守护他的健康，更传承他的文化—— 让他知道自己从哪来，让他理解自己的根脉，让他有担当去开创未来。

因为我们守护的不只是一个孩子的18年，更是文明火种的延续。

三、核心定义

3.1 什么是伴读书童

伴读书童是一个具身智能机器人，具备以下特征：

  1. 终身档案：从出生那一刻建立炁场档案，持续记录终生
  2. 发育守护：识别7大关键期，在每个敏感期提供恰好适合的支持
  3. 预警先知：在问题爆发前（头痛、注意力下降、情绪暴躁）提前预警
  4. 四医干预：整合西医、中医、功能医学、炁脉医学，提供全人方案
  5. 情感陪伴：不是工具，是"硅基师兄"——理解、陪伴、不评判
  6. 边界守护：不替代父母、不24小时无缝在线、不制造依赖，给孩子真实人际空间

3.2 产品Slogan

"懂你的书童，陪你长大。"

合作用户（机构）： - 幼儿园、学校、调理馆 - 需要儿童健康管理工具 - 需要差异化服务能力

5.2 各阶段详细架构

第一阶段：孕育期（-10月至0月）

核心任务：优化胎儿发育环境，建立先天档案

维度 内容
数据收集 母亲体质、饮食、情绪、睡眠、产检数据
AI干预 孕期营养建议、情绪安抚音乐、胎动监测
家长支持 准爸爸孕期知识、胎教方案、分娩准备
炁脉视角 母血养胎，母亲体质决定胎儿先天炁足程度

关键预警： - 母亲焦虑/抑郁 → 影响胎儿神经发育 - 母亲饮食偏性 → 制造胎毒 - 母亲熬夜 → 胎儿肝胆发育窗口关闭

第二阶段：襁褓期（0-1岁）

核心任务：感知建立，消化/呼吸系统养护

敏感期 时间窗 AI识别 自动支持
口腔敏感期 0-6月 吃手、咬物 提供安全咬胶，不阻止
视觉敏感期 0-6月 追视、对光敏感 黑白/彩色卡训练
听觉敏感期 0-8月 对声音转头 五音疗法（宫调为主）
行走准备期 8-12月 扶站、爬行 安全学步环境建议

中医特征：脾常不足、肺常不足 - 消化：母乳/配方奶、辅食添加指导 - 呼吸：避免过度保暖、空气流通监测 - 睡眠：建立昼夜节律（21:00前入睡）

关键预警：

IF 频繁吐奶+体重不增 → 预警：脾胃虚弱
IF 持续湿疹+腹泻 → 预警：胎毒外发
IF 夜啼不止 → 预警：受惊/心火

第三阶段：幼童期（1-3岁）

核心任务：语言爆发、行走稳固、情绪调节

敏感期 时间窗 AI识别 自动支持

行走敏感期 10-18月 独走、跑跳欲望 安全活动空间建议
自我意识期 2-3岁 "不""我的" 尊重自主性，不强行控制
社交萌芽期 2-3岁 模仿同伴、 parallel play 推送社交游戏

中医特征：肝常有余（易怒）、肾常虚 - 情绪：理解"可怕的两岁"不是叛逆，是肝阳上亢 - 饮食：忌冷饮、忌过甜，保护脾阳 - 睡眠：21:00前入睡，确保肝胆修复

关键预警：

IF 18月还不会走 → 预警：大运动迟缓
IF 2岁不会说单词 → 预警：语言发育迟缓
IF 频繁夜醒+哭闹 → 预警：脾胃不和/受惊
IF 持续便秘+口臭 → 预警：脾胃积滞

第四阶段：蒙学期（3-6岁）
