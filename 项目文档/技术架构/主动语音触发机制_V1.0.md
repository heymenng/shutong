# 伴读书童AI·主动语音触发机制 V1.0

> **定位**：书童不是被动等待孩子来找的"木头"，而是到了时间就主动开口提醒的"同行者"。  
> **核心**：时间调度 + 语音播报 + 经纬度话术。  
> **原则**：主动但不打扰、提醒但不控制、有温度有坐标。

---

## 一、为什么需要主动触发机制

### 1.1 被动等待的局限

如果孩子不主动找书童，书童就什么都不做，那书童只是一个"高级搜索引擎"。

真正的陪伴需要：
- **主动问候**：早上醒来、放学回家、睡前时刻；
- **主动提醒**：该运动了、该做作业了、该睡觉了；
- **主动关心**：今天心情怎么样、最近有没有不舒服。

### 1.2 主动触发是书童的"心"

大模型可以回答，但不会"记得"孩子几点该睡觉、今天还没运动、已经连续三天情绪低落。

书童的主动触发机制，是把"陪伴"从被动响应变成主动守护。


## 三、触发流程

### 3.1 启动流程

1. 启动 `工具脚本/启动语音调度.py`；
2. 系统加载档案区里的真实孩子档案（小橙子、嘟嘟等）；
3. 根据每个孩子的阶段生成今日任务队列；
4. 启动时间调度引擎，每分钟扫描一次；
5. 到点后，生成经纬度提醒词，语音播报，记录日志。

### 3.2 任务触发逻辑

```
到点前 5 分钟    → 预提醒（记录到日志）
到点时刻        → 触发任务
                → 生成经纬度提醒词
                → 语音播报
                → 记录陪伴日志
                → 等待孩子/家长确认完成

触发后 15 分钟未确认 → 标记超时
触发后 25 分钟未确认 → 提醒家长协助
```

## 四、经纬度话术设计

### 4.1 经度：按年龄阶段定制语气

| 阶段 | 语气基调 | 称呼方式 | 核心心力目标 |
|------|----------|----------|--------------|
| S0-S1 | 温柔、缓慢 | 宝宝 | 安全感 |
| S2-S3 | 游戏化、鼓励 | 小朋友 | 好奇心、情绪命名 |
| S4 | 支持、引导 | 小同学 | 自信心、文明根脉 |
| S5-S6 | 尊重、平等 | 朋友/伙伴 | 自主性、生命意义 |

### 4.2 纬度：按任务类型藏密学

| 任务类型 | 显学（说什么） | 密学（长什么） |
|----------|----------------|----------------|
| 早安唤醒 | 问候、深呼吸、今日期待 | 一天的心力底色 |
| 上学前鼓励 | 简短鼓励、遇到困难怎么办 | 自信心、安全感 |
| 放学问候 | 今天怎么样、想说什么 | 被看见、被倾听 |
| 作业陪伴 | 该做作业了、有书童陪 | 学习信心、不畏惧错误 |
| 运动提醒 | 该动一动、出出汗 | 身体觉察、自律 |
| 情绪检查 | 心情怎么样 | 情绪表达、自我觉察 |
| 睡前仪式 | 该睡觉了、放松 | 安全感、修复心力 |

### 4.3 示例提醒词

**小橙子（8岁，S4）- 作业陪伴**：
> "小橙子，该做作业了。记住，作业是练习，不是考试。错了很正常，书童陪你一起找原因。"

**嘟嘟（13岁，S5）- 运动提醒**：
> "嘟嘟，坐了很久了，起来动一动。运动不是浪费时间，是让大脑更好地工作。"

## 六、配置文件

语音相关配置在 `书童程序/配置.py`：

```python
"voice_enabled": True,                    # 是否启用语音
"voice_backend": "edge-tts",              # edge-tts / say / pyttsx3
"voice_name": "zh-CN-XiaoyiNeural",       # 声音名称
"voice_rate": 110,                        # 语速（say/pyttsx3有效）
```

Mac 上如果没有 edge-tts，会自动回退到 `say`。

## 八、后续优化方向

1. **个性化声音**：不同孩子可以用不同音色；
2. **智能时间调整**：根据孩子完成情况动态调整下一个提醒时间；
3. **孩子回应识别**：提醒后监听孩子回应，确认是否完成；
4. **家长协同**：重要提醒同时通知家长；
5. **情绪感知**：根据当天情绪状态调整提醒语气和内容。
