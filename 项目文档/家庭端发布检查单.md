# 书童家庭端发布检查单

> 每次修改 `书童家庭端.html` 或相关后端接口后，必须逐项勾选并通过。
> 此检查单由 2026-06-26 "发不出去消息" 事件倒逼生成，目的是不让师父再当测试员。

## 一、本地服务健康

- [ ] 服务能启动，无启动期报错
- [ ] `http://127.0.0.1:3876/` 返回 200
- [ ] `http://127.0.0.1:3876/master` 返回 200
- [ ] `/api/chat` POST 能返回正常 JSON 回复
- [ ] `/api/voices` 返回讯飞发音人列表
- [ ] `/api/tts` 能合成语音

## 二、页面静态检查（自动化）

- [ ] 所有 `getElementById` 都有对应 `id`
- [ ] `sendMessage`、`handleKeyDown`、`switchRole`、`playChatAudio` 等关键函数存在
- [ ] 无孤立的代码块（函数名缺失、括号不匹配）
- [ ] 无重复的 `id`

## 三、浏览器真实点击测试

- [ ] 页面加载后顶部状态条不显示 JS 错误
- [ ] 输入框能获取焦点、能打字
- [ ] 点击「发送」按钮，消息立即出现在对话框
- [ ] 按 Enter 键也能发送
- [ ] 能收到书童文字回复
- [ ] 打开「语音播报」开关后，回复能朗读出声

- [ ] 关闭「语音播报」后不再朗读
- [ ] 家长/孩子切换下拉框能切换，且界面元素正确显隐
- [ ] 孩子模式下不显示「提醒」和「档案编辑」

## 四、局域网访问测试

- [ ] 另一台设备访问 `http://192.168.0.212:3876/` 能打开
- [ ] 另一台设备能发送消息并收到回复

## 五、回归检查

- [ ] 修改家庭端后，确认没有破坏师父端 `/master`
