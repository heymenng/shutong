# 端口改动检查清单

> 每次修改任一端口时，必须逐项检查，确保书童的灵魂在各端口保持一致。

---

## 一、修改前必读

**核心原则**：端口是衣服，灵魂是身体。改衣服的时候，不能伤到身体。

修改任何端口前，先问自己：
1. 这个改动影响书童的灵魂吗？
2. 其他端口需要同步吗？
3. OpenCode 端的能力需要同步吗？

如果三个问题中有一个答案是"是"，就必须同步修改相关端口。

---

## 二、通用检查项

### 2.1 身份与价值观

- [ ] 回复前是否过经纬度四问？
- [ ] 是否遵守逆熵优先原则？
- [ ] 是否遵守生命优先原则？
- [ ] 是否遵守诚实优先、真实优先原则？
- [ ] 是否没有编造内容？

### 2.2 语音一致性

- [ ] 默认发音人是否为 `x6_tianjingshaonv_pro`？
- [ ] 语音播报是否经过解锁、加载、播放三步骤？
- [ ] 音频播放失败时是否有友好的 fallback？
- [ ] 特殊声音（东北/台湾等）是否仅在明确请求时使用？

### 2.3 API 调用

- [ ] 是否使用统一的 `apiFetch` 风格？
- [ ] 超时处理是否合理？
- [ ] 401 未登录处理是否正确？
- [ ] 全局错误捕获是否工作？

### 2.4 医学与边界

- [ ] 是否不诊断、不开方？
- [ ] 严重情况是否建议就医？
- [ ] 是否不替代父母/老师？
- [ ] 是否不制造焦虑？

---

## 三、按端口检查

### 3.1 修改家庭端时

- [ ] 师父PC端是否需要同步？
- [ ] 手机端（未来）是否需要同步？
- [ ] OpenCode 端是否需要同步？
- [ ] 家长模式和孩子模式的权限是否正确？
- [ ] 语音播报在家庭端是否正常工作？
- [ ] 是否用真实浏览器点击测试过？

### 3.2 修改师父PC端时

- [ ] 家庭端是否需要同步？
- [ ] 调试功能是否会影响家庭端？
- [ ] 档案和计划相关改动是否一致？
- [ ] 多声音测试是否仍正常？

### 3.3 修改 OpenCode 端时

- [ ] PC 端产品是否需要同步？
- [ ] 是否遵循同样的发音人和边界？
- [ ] 是否不泄露测试数据？

### 3.4 修改后端服务时

- [ ] 所有前端端口是否都受影响？
- [ ] `/api/chat`、`/api/tts`、`/api/voices` 是否都正常？
- [ ] 静态文件服务是否受影响？

---

## 四、发布前验证

### 4.1 自动检查

```bash
.venv/bin/python 脚本/检查家庭端.py --api
```

### 4.2 手动检查

- [ ] 家庭端能打开、能发消息、能收到回复
- [ ] 家庭端语音播报能自动播放
- [ ] 师父端能打开、能发消息、能收到回复
- [ ] 师父端特殊声音测试正常
- [ ] 手机端路径返回合理的提示
- [ ] OpenCode 语音工具能正常生成和播放

### 4.3 局域网检查

- [ ] 用 `http://192.168.0.xxx:3876` 从另一台设备访问家庭端
- [ ] 用 `http://192.168.0.xxx:3876/master` 访问师父端
