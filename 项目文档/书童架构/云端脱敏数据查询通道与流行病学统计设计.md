# 云端脱敏数据查询通道与流行病学统计设计

> **性质**：书童架构文档  
> **目的**：让师父能在师父PC端随时调取脱敏后的群体统计，支持趋势分析与流行病学监测  
> **核心原则**：本地存明细，云端只存脱敏后的标签与成果；任何查询必须不可逆查个体

---

## 一、设计目标

1. **每个家庭云端独立数据区**：以家庭为单位隔离，云端 family_id 与本地 family_id 做加盐哈希映射。
2. **自动/手动上传脱敏数据**：孩子画像、家庭结构、陪伴目标、训练成果、健康事件标签。
3. **师父随时发起统计查询**：通过师父PC端选择维度，实时返回聚合结果。
4. **支持流行病学监测**：如季节性流感、过敏、情绪问题爆发等群体的百分比与趋势。
5. **支撑长期研究**：为四医合诊、发育规律、教育方法有效性积累可分析的脱敏数据集。

---

## 二、数据分层

| 层级 | 位置 | 内容 | 谁可以访问 |
|------|------|------|-----------|
| 原始明细层 | 本地家庭目录 | 完整对话、日记、作业、音频、医学记录 | 本家庭、本地书童 |
| 脱敏画像层 | 云端家庭数据区 | 标签化画像、家庭结构、关注问题、训练记录、成果指标 | 云端服务、授权查询接口 |
| 聚合统计层 | 云端聚合数据库 | 跨家庭统计结果、趋势曲线、分组对比 | 师父PC端、研究接口 |

**不可上传的原始信息：**
- 真实姓名、昵称、学校、班级、老师姓名
- 精确出生日期（只能保留年龄段）
- 详细家庭住址、电话、身份证号
- 完整对话原文、日记原文
- 未经脱敏的医学诊断报告

├── family_index.json                 # 家庭索引（仅哈希ID + 最后同步时间）

│   │   └── ...

## 四、脱敏上传通道

### 4.1 上传触发方式

1. **定时自动上传**：每天凌晨本地书童自动把前一天新增的脱敏标签同步到云端。
2. **手动上传**：家长在家庭端点击“同步数据到云端（仅脱敏标签）”。
3. **师父查询时即时聚合**：若云端数据不够新，师父PC端可请求本地端做一次增量同步（需本家庭授权）。

### 4.2 脱敏流程

```
本地原始数据
    │
    ▼
[脱敏器] ① 去除PII ② 泛化年龄/地点 ③ 症状转标签 ④ 对话转摘要
    │
    ▼
[标签化] 生成标准标签与指标
    │
    ▼
[加密哈希] family_id → hashed_family_id, child_name → child_hash
    │
    ▼
上传到云端家庭数据区
```

### 4.3 本地脱敏器模块（建议新增）

建议新增文件：`书童程序/核心/数据脱敏器.py`

核心方法：
- `sanitize_family_profile(family_json)`
- `sanitize_child_profile(child_json)`
- `extract_health_events(records)`
- `extract_outcome_metrics(records)`
- `hash_id(local_id, salt)`

### 5.3 预置统计报表

师父PC端提供一键报表：

1. **流行病学监测**
   - 本季节流感率、手足口、过敏、鼻炎等百分比
   - 按城市级别、年龄组、家庭学历分组
   - 周趋势曲线

2. **家庭画像分布**
   - 总家庭数、总孩子数
   - 家长学历分布饼图
   - 家庭结构分布
   - 城市级别分布

3. **关注标签统计**
   - 各年龄段最常见关注标签 Top 10
   - 博士家庭 vs 普通家庭标签差异

4. **训练成果统计**
   - 各方法有效率（改善数 / 总数）
   - 各年龄段改善率
   - 长期趋势（季度对比）

## 六、流行病学监测示例：冬季流感

**场景**：师父问“今年冬天我们陪伴的孩子里，流感比例是多少？博士家庭和普通家庭有差别吗？”

**系统响应：**

1. 查询云端 `health_events.json` 中 `event_type=流感` 且 `season=2026-冬季` 的记录。
2. 关联 `family_profile.json` 中的 `parent_highest_edu`。
3. 返回：

```
总孩子数：62
流感发生数：21
流感率：33.9%

按家长学历分组：
- 博士家庭：18人，流感5人，率27.8%
- 硕士家庭：22人，流感7人，率31.8%
- 本科及以下：22人，流感9人，率40.9%

按年龄组：
- 0-3岁：率45.5%
- 3-6岁：率38.9%
- 6-12岁：率28.0%

周趋势：
W01: 12% → W02: 28% → W03: 35% → W04: 30%
```

**价值**：
- 及时发现群体健康风险
- 为家庭推送预防建议
- 为研究方法提供真实世界数据

## 七、隐私与安全铁律

1. **不可逆查**：任何聚合查询返回的结果必须无法反推出具体家庭或孩子。
2. **最小分组**：当某分组样本量 < 5 时，不显示具体数字，仅显示“样本不足”。
3. **授权上传**：家庭默认关闭自动上传，首次同步需家长明确同意。
4. **数据保留**：云端只保留标签和指标，不保留原始对话、日记、图片。
5. **传输加密**：所有上传和查询使用 HTTPS。
6. **访问控制**：只有师父账号和授权研究账号能访问聚合查询接口。
