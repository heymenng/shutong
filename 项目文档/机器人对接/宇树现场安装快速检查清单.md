## 二、现场网络配置

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 机器人开机，连接网线到路由器/交换机 | 机器人启动完成 |

## 三、书童配置切换

修改 `书童程序/配置.py`：

```python
# H1 直接 SDK 连接
"unitree_enabled": True,
"unitree_mode": "real",
"unitree_model": "h1",
"unitree_network_interface": "en0",  # 根据实际网卡修改
"unitree_robot_ip": "192.168.123.161",

# 或 G1 虚拟机桥接（保持默认即可）
"unitree_enabled": True,
"unitree_mode": "simulation",  # G1 桥接不依赖本地模式
```

> 注意：G1 通过虚拟机桥接时，本地书童界面会自动检测并使用 `UnitreeG1Bridge`。

## 五、安全红线

| 项目 | 要求 |
|---|---|
| 安全距离 | 机器人动作时周围 2 米内无儿童、无障碍物 |
| 急停 | 演示人员必须站在能随时按急停的位置 |
| 首次动作 | 必须先点「停止」，确认机器人响应正常后再试其他动作 |
| 速度 | 首次移动速度不超过 0.2 m/s |
| 电量 | 低于 20% 时停止演示，先充电 |
| 异常 | 任何动作超时、机器人姿态异常，立即按急停 |

## 六、常见问题速查

| 现象 | 排查 |
|---|---|
| 机器人状态显示「未连接」 | 检查 `unitree_enabled=True`；检查 Mac 与机器人网络；检查网卡名 |
| G1 桥接 `unitree_sdk_available: false` | 进入虚拟机执行 `python3 -c "import unitree_sdk2py"`，如失败则重新安装 |
| 动作发送后超时 | 无真实机器人时正常；有真机时检查 DDS 多播、Domain ID、防火墙 |
| H1 动作无响应 | 确认 H1 IP 正确；确认 Mac IP 设置为 `192.168.123.99`；确认网卡名 |
| 语音没出来 | 检查 Mac 扬声器/机器人音箱；检查 `voice_enabled=True` |
