## 二、三个端口的设计

### 2.1 端口分工

| 端口 | 路径 | 用途 | 用户 |
|---|---|---|---|
| 家庭端 | `/family/<family_id>` | 家长/孩子日常使用 | 家庭成员 |
| 手机端 | `/mobile/<family_id>` | 移动设备优先 | 家庭成员 |
| 师父端 | `/master/<family_id>` | 训练书童、查看数据 | 师父/开发者 |

### 2.2 为什么用固定子路径

早期用 `?family=<id>` 参数，导致：
- 浏览器/PWA 缓存页面后，容易串到别的家庭
- `localStorage` 记住上次家庭，打开不带参数的链接就串网

改为固定子路径后：
- `/family/default_family` 永远返回刘清源家庭
- `/mobile/family_guodongling` 永远返回郭冬玲家庭
- 服务端向 HTML 注入 `window.LOCKED_FAMILY_ID`，前端优先使用

### 2.3 后端路由核心代码

```python
parsed_path = urllib.parse.urlparse(decoded_path).path

# 家庭端固定子路径
if re.match(r"^/family/([^/]+)$", parsed_path):
    family_id = re.match(r"^/family/([^/]+)$", parsed_path).group(1)
    html_content = html_path.read_text(encoding="utf-8")
    inject = f"<script>window.LOCKED_FAMILY_ID = '{family_id}';</script>"
    html_content = html_content.replace("</head>", f"{inject}\n</head>")
    self._send_static(html_content, no_cache=True)

# 手机端同理
if re.match(r"^/mobile/([^/]+)$", parsed_path):
    ...

# 师父端同理
if re.match(r"^/master/([^/]+)$", parsed_path):
    ...
```

### 2.4 前端如何锁定家庭

每个 HTML 头部有公共 JS 注入，前端 `parseFamilyParam()`：

```javascript
function parseFamilyParam() {
    // 优先使用服务端注入的锁定家庭 ID
    if (window.LOCKED_FAMILY_ID) {
        appState.familyId = window.LOCKED_FAMILY_ID;
        appState.lockedFamily = true;
        localStorage.setItem('bookboy_family_id', window.LOCKED_FAMILY_ID);
        // 隐藏家庭切换下拉框
        const sel = document.getElementById('familySelect');
        if (sel) sel.style.display = 'none';
        return;
    }
    // 兼容旧 ?family= 参数
    ...
}
```

### 3.2 同步脚本

### 3.3 家庭成员身份识别

每个家庭 JSON 包含 `members`：

```json
{
  "user_id": "u_liuqingsong",
  "name": "刘劲松",
  "role": "家长",
  "relation": "伯父/父亲"
}
```

前端选择身份后，发送消息时带上：
- `user_id`：当前说话者
- `family_id`：当前家庭
- `child_id`：当前对话的孩子

后端 `/api/chat` 根据 `user_id` 判断是家长/孩子/师父，决定语气、称呼和权限。

## 四、外网部署方案

### 4.1 方案选择：cloudflared tunnel

本地服务只能局域网访问，外网需要隧道工具。选择 cloudflared tunnel 的原因：
- 免费
- 不需要公网 IP
- 不需要配置路由器端口映射
- 自动生成 HTTPS 域名

### 4.2 启动命令

```bash
cloudflared tunnel --url http://127.0.0.1:3876
```

启动后控制台会输出：
```
https://xxxxx.trycloudflare.com
```

这个域名就是外网入口。

### 4.3 外网链接格式

把本地 `http://127.0.0.1:3876` 替换为 cloudflare 域名即可：

| 本地 | 外网 |
|---|---|
| `http://192.168.0.131:3876/family/default_family` | `https://xxxxx.trycloudflare.com/family/default_family` |
| `http://192.168.0.131:3876/mobile/family_guodongling` | `https://xxxxx.trycloudflare.com/mobile/family_guodongling` |
| `http://192.168.0.131:3876/master/family_lanxin` | `https://xxxxx.trycloudflare.com/master/family_lanxin` |

### 4.4 注意事项

- **域名会变**：每次重启 cloudflared 后，trycloudflare.com 的随机子域名会变化
- **不要长期依赖**：免费 tunnel 适合测试和临时使用，正式部署需要固定域名（cloudflare 固定 tunnel 或购买域名）
- **HTTPS 已启用**：trycloudflare.com 自动 HTTPS，手机浏览器不会报不安全

### 4.5 防火墙

Mac 系统防火墙可能阻止外部连接：

```bash
# 查看状态
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate

# 关闭（开发测试用）
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setglobalstate off
```

## 五、语音播放方案

### 5.1 语音合成

- **后端**：讯飞超拟人 API，发音人固定 `x6_tianjingshaonv_pro`
- **接口**：`POST /api/tts`，返回 `/audio/<hash>.mp3`
- **缓存**：语音文件存在 `03-引擎区/书童程序/数据/语音缓存/`，相同文本会复用

### 5.2 移动端播放限制

iOS Safari 和 Android Chrome 禁止自动播放音频，必须用户点击后播放。

解决方案：
- 书童回复文字后，消息下方显示 **"🔊 点击播放"** 按钮
- 用户点击后，再合成/播放语音
- 后台也会提前合成，用户点的时候如果已经合成好就直接播

### 5.3 公共 JS 音频函数

所有端口共用 `03-引擎区/static/书童公共.js`：
- `unlockAudio()`：在用户手势中解锁音频上下文
- `playChatAudio(url, label)`：优先用 Web Audio API，fallback HTMLAudioElement
- `playAudioWithWebAudio(url, label)`：移动端兜底方案

## 六、取消密码的设计

本地家庭使用场景，输入密码麻烦，且容易泄露。改为：

### 后端

```python
if self.path == "/api/login":
    # 本地家庭场景：取消密码，直接登录
    role = "adult"
    if data.get("password") == ui_passwords.get("master"):
        role = "master"
    token = secrets.token_urlsafe(32)
    sessions[token] = {"role": role, ...}
    self._send_json({"token": token, "role": role})
```

### 前端

页面加载后自动调用 `/api/login`，无需用户输入密码：

```javascript
async function doLogin() {
    const res = await apiFetch('/api/login', {
        method: 'POST',
        body: JSON.stringify({ password: '' })
    });
    const data = await res.json();
    if (data.token) {
        appState.token = data.token;
        localStorage.setItem('bookboy_token', data.token);
        // 继续加载家庭、选择身份
    }
}
```

## 七、防止串网的完整措施

1. **固定子路径**：`/family/<id>`、`/mobile/<id>`、`/master/<id>`
2. **服务端注入锁定**：`window.LOCKED_FAMILY_ID`
3. **前端优先使用锁定 ID**，忽略 localStorage
4. **HTML/JS 全部加 no-cache 头**
5. **静态资源加版本号**：`书童公共.js?v=2`
6. **不带参数的 `/mobile` 不自动加载 localStorage**，强制显示家庭选择
7. **建议用户首次使用前清除浏览器缓存**

## 十、常见问题

### Q1：为什么外网比内网慢？
A：cloudflare tunnel 需要把本地流量转发到公网，有额外延迟。页面大时更明显。

### Q2：为什么手机端没声音？
A：移动端禁止自动播放，必须用户点 **"🔊 点击播放"** 按钮。

### Q3：为什么串网？
A：旧缓存或旧链接导致。用固定子路径链接，清除浏览器缓存。

### Q4：cloudflare 域名变了怎么办？
A：免费 tunnel 每次重启会变。需要固定域名的，配置 cloudflare 固定 tunnel 或购买域名。
