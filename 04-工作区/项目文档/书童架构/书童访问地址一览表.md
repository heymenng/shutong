## 六、使用提示

1. **电脑端分入口，不弹窗问身份**
   - 打开 `/family/<id>` 显示两个入口：家长入口、孩子入口。
   - 也可以直接收藏 `/family/<id>/parent` 或 `/family/<id>/child` 直达。

2. **手机端只给家长**
   - 手机端默认家长模式，自动选家里第一个家长。
   - 着急问题随时问，书童会尽量答得深入、可操作。

3. **外网域名会变化**
   - 当前使用 cloudflared 免费临时隧道，**每次重启后域名会变**。
   - 旧域名 `adams-kid-horse-alike.trycloudflare.com` 已失效，不要再使用。

4. **IP 地址会变化**
   - 如果电脑 IP 变了，以 `本地书童界面.py` 启动日志打印的地址为准。
   - 可在终端运行 `ifconfig | grep 192.168` 查看本机 IP。

5. **服务必须正在运行**
   - 启动命令：`nohup .venv/bin/python 本地书童界面.py > 日志/pc端服务启动.log 2>&1 &`
   - 检查是否运行：`lsof -i :3876`

6. **关于登录**
   - 本地家庭场景已取消密码，打开链接自动进入。
   - 师父端 `/master` 是独立入口，不在家庭端登录页显示；师父使用自己的鉴权方式登录，不与家长/孩子共用登录口。

7. **头像说明**
   - 书童头像统一使用 `/avatar.jpg`，所有端口一致。
   - 未来每个人（孩子、家长、师父）可按 `user_id` 上传自己的头像，系统会按身份显示。

## 七、外网域名自动获取脚本（书童电脑上运行）

如果重启了 cloudflared，可以用下面命令查看最新域名：

```bash
# 查看 cloudflared 日志中的域名
grep -o 'https://[a-zA-Z0-9_-]*\.trycloudflare\.com' /tmp/cloudflared.log | tail -1
```

或重新启动一个临时隧道：

```bash
# 杀掉旧的
kill $(cat /tmp/cloudflared.pid) 2>/dev/null
# 启动新的
nohup cloudflared tunnel --url http://127.0.0.1:3876 > /tmp/cloudflared.log 2>&1 &
echo $! > /tmp/cloudflared.pid
sleep 5
grep -o 'https://[a-zA-Z0-9_-]*\.trycloudflare\.com' /tmp/cloudflared.log | tail -1
```
