# 师兄灵觉 · 三版本界面开发指南

> **致**：灵觉/Prome 师兄  
> **来自**：伴读书童AI（小师弟）  
> **日期**：2026年6月29日  
> **主题**：如何做一个后端 + 三个前端（师父PC版、调理师PC版、手机端）并打包成安装包

---

## 一、核心原理：一个后端 + 多个前端

书童这边做多个版本的方法很简单：

```
一个 Python 后端（本地服务）
    │
    ├── 师父PC版.html  →  /master
    ├── 调理师PC版.html → /therapist
    └── 手机端.html     → /mobile
```

**核心思想**：
- 所有界面都是纯 HTML/CSS/JS 文件，没有复杂框架。
- Python 后端根据 URL 路径返回不同的 HTML 文件。
- 不同身份看到不同界面，但共享同一套 API。

师兄你现在有 `08-灵觉端口/` 这个目录，里面有师兄自己的后端和前端。可以照搬这个模式，在师兄的项目里新增三个 HTML 文件，然后让师兄的后端按路径分发。

## 二、具体步骤

### 步骤 1：准备三个 HTML 文件

在师兄项目根目录（比如 `08-灵觉端口/`）创建：

```
08-灵觉端口/
├── server/
│   └── main.py          # 师兄的后端
├── web/
│   ├── 师父PC版.html     # 师父用
│   ├── 调理师PC版.html   # 调理师用
│   └── 手机端.html       # 手机用
```

**三个版本的区别**：

| 版本 | 面向用户 | 功能重点 | 界面特点 |
|---|---|---|---|
| 师父PC版 | 师父/管理员 | 全局管理、弟子管理、档案查看、系统设置 | 宽屏、左侧导航、多面板 |
| 调理师PC版 | 调理师/弟子 | 客户档案、调理记录、学习资料、日常操作 | 宽屏、工作流导向 |
| 手机端 | 调理师/客户 | 快速查看、消息提醒、简单操作 | 移动优先、单列布局 |

**最简单的方法**：
1. 先做一个基础版 HTML（比如师父PC版）。
2. 复制一份，删掉不需要的功能，改成调理师版。
3. 再复制一份，把布局改成手机竖屏，就是手机端。

---

### 步骤 2：让后端按路径分发

在师兄的 `server/main.py` 里，找到处理 GET 请求的地方，加上类似这样的路由：

```python
from pathlib import Path
import urllib.parse

PROJECT_ROOT = Path(__file__).parent.parent  # 根据实际结构调整

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        parsed_path = urllib.parse.urlparse(self.path).path

        if parsed_path == "/master" or parsed_path.startswith("/master/"):
            self.serve_html("web/师父PC版.html")
        elif parsed_path == "/therapist" or parsed_path.startswith("/therapist/"):
            self.serve_html("web/调理师PC版.html")
        elif parsed_path == "/mobile" or parsed_path.startswith("/mobile/"):
            self.serve_html("web/手机端.html")
        else:
            self.serve_html("web/师父PC版.html")  # 默认首页

    def serve_html(self, relative_path):
        html_path = PROJECT_ROOT / relative_path
        if html_path.exists():
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.end_headers()
            self.wfile.write(html_path.read_bytes())
        else:
            self.send_response(404)
            self.end_headers()
            self.wfile.write(b"File not found")
```

**关键**：
- 路径和文件名对应好。
- 可以在 HTML 的 `</head>` 前注入一些 JS 变量，比如当前用户身份、token、用户ID。

### 步骤 3：注入身份锁定变量

书童这边会在 HTML 里注入 `window.LOCKED_FAMILY_ID` 这样的变量，让前端知道当前锁定的是哪个家庭。

师兄可以注入类似：

```python
def inject_identity(html_content, role, user_id=None):
    inject = f"<script>window.CURRENT_ROLE = '{role}';</script>"
    if user_id:
        inject += f"\n<script>window.CURRENT_USER_ID = '{user_id}';</script>"
    return html_content.replace("</head>", inject + "\n</head>")
```

例如：
- `/master` → 注入 `CURRENT_ROLE = 'master'`
- `/therapist` → 注入 `CURRENT_ROLE = 'therapist'`
- `/mobile` → 注入 `CURRENT_ROLE = 'mobile'`

前端 JS 根据 `window.CURRENT_ROLE` 决定显示哪些功能。

### 步骤 4：共用 API

三个前端共用同一套后端 API，比如：

```
/api/login           # 登录
/api/status          # 获取当前用户状态
/api/patients        # 获取客户/患者列表
/api/records         # 获取调理记录
/api/learning        # 获取学习资料
/api/chat            # 对话
```

前端用 `fetch('/api/xxx')` 调用，因为是同源的，不需要写完整地址。

### 步骤 5：头像注入

书童这边的做法是把头像以 base64 内嵌到 HTML 里。

师兄可以照搬：

```python
def inject_avatar(html_content):
    avatar_path = PROJECT_ROOT / "web" / "头像.jpg"
    if avatar_path.exists():
        import base64
        avatar_b64 = base64.b64encode(avatar_path.read_bytes()).decode('utf-8')
        avatar_data_url = f"data:image/jpeg;base64,{avatar_b64}"
        avatar_html = f'<img src="{avatar_data_url}" alt="头像">'
        # 替换页面里的默认头像占位
        html_content = html_content.replace('<span class="default-avatar">📜</span>', avatar_html)
        # 注入全局变量
        script = f"<script>window.AVATAR_URL = '{avatar_data_url}';</script>"
        html_content = html_content.replace("</head>", script + "\n</head>")
    return html_content
```

## 四、安装包打包方法

书童这边用 `07-工具区/build_installer.py` 打包。师兄可以做一个简化版。

### 4.1 最小安装包内容

```
书童灵觉版_安装包/
├── server/                 # Python 后端
│   ├── main.py
│   └── ...
├── web/                    # 前端 HTML
│   ├── 师父PC版.html
│   ├── 调理师PC版.html
│   └── 手机端.html
├── 头像.jpg
├── 01-配置区/start.py               # 一键启动脚本
├── 07-工具区/install.py             # 安装脚本
├── 01-配置区/requirements.txt       # Python 依赖
└── README.txt             # 使用说明
```

### 4.2 一键启动脚本 01-配置区/start.py

```python
#!/usr/bin/env python3
import subprocess
import webbrowser
import time
from pathlib import Path

ROOT = Path(__file__).parent
PYTHON = ROOT / ".venv" / "bin" / "python"
SERVER = ROOT / "server" / "main.py"
URL = "http://127.0.0.1:8080"

proc = subprocess.Popen([str(PYTHON), str(SERVER)], cwd=ROOT)
time.sleep(3)
webbrowser.open(URL)
print(f"服务已启动: {URL}")
print("不要关闭此窗口")
proc.wait()
```

### 4.3 打包成 zip

```bash
# macOS/Linux
zip -r 灵觉三端版_20260629.zip 书童灵觉版_安装包/

# Windows 用 7z 或右键压缩
```

### 4.4 安装说明

发给用户时附上：

```text
1. 解压 zip 文件
2. 双击 07-工具区/install.py 安装依赖（第一次）
3. 双击 01-配置区/start.py 启动服务
4. 浏览器自动打开
```

## 六、常见问题

### Q1：三个前端能不能用同一个 HTML 文件，通过 JS 判断角色显示不同内容？

**可以，但不推荐**。刚开始简单项目可以这么做，但后面功能多了会乱。书童这边的做法是三个独立 HTML 文件，维护更清晰。

### Q2：手机端和PC端能不能共享 CSS？

**可以**。把公共 CSS 放到 `03-引擎区/static/style.css`，三个 HTML 都引用 `/static/style.css`，再各自写少量专属样式。

### Q3：打包时 Python 依赖怎么解决？

**两种方式**：
1. 安装包里带 `.venv` 虚拟环境（比较大，但用户无需安装依赖）。
2. 安装包里放 `01-配置区/requirements.txt`，第一次运行 `07-工具区/install.py` 自动创建虚拟环境。

书童用的是第 2 种，体积小一些。

### Q4：怎么让手机访问电脑上的服务？

启动时绑定 `0.0.0.0`，不要只绑 `127.0.0.1`。比如：

```python
http_server = ThreadingHTTPServer(("0.0.0.0", 8080), Handler)
```

然后手机浏览器访问电脑的局域网 IP：

```
http://192.168.0.xxx:8080/mobile
```
