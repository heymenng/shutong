## 二、两种运行模式

### 1. 模拟模式（单机即可运行）

不需要真实机器人，电脑上即可测试书童与机器人的交互逻辑。

```python
{
    "unitree_enabled": True,
    "unitree_mode": "simulation",
    "unitree_model": "go2"
}
```

### 2. 真实模式（需要真实机器人）

需要：
- 宇树机器人一台
- 电脑与机器人通过网线/WiFi 连接
- 电脑 IP 设置为 `192.168.123.99`
- 机器人 IP 通常为 `192.168.123.161`

```python
{
    "unitree_enabled": True,
    "unitree_mode": "real",
    "unitree_model": "go2",
    "unitree_network_interface": "en0"  # macOS 用 en0，Ubuntu 用 enp3s0 等
}
```

## 五、接口使用示例

```python

bb = BookBoySystem()
```

## 六、配置开关

在 `03-引擎区/书童程序/配置.py` 中：

```python
"unitree_enabled": False,           # 是否启用
"unitree_mode": "simulation",       # simulation / real
"unitree_model": "h1",              # h1 / h2 / go2 / b2 / g1
"unitree_network_interface": "en0", # 网卡名
"unitree_domain_id": 0,             # DDS domain ID
"unitree_robot_ip": "192.168.123.161",  # 机器人 IP
```

---

## 七、真实模式网络配置（简要）

1. 用网线连接机器人和电脑
2. 查看网卡名：`ifconfig`（macOS）或 `ip link`（Ubuntu）
3. 设置电脑 IPv4：
   - 地址：`192.168.123.99`
   - 子网掩码：`255.255.255.0`
4. 修改配置中的 `unitree_network_interface` 为实际网卡名
5. 启动书童系统，开启 `unitree_enabled: True` 和 `unitree_mode: "real"`

---

## 八、安全边界

- 机器人控制指令**不包含危险动作**（不触发后空翻、跳跃等）
- 所有动作都是温和的：站立、坐下、Hello、慢速行走
- 真实模式下首次使用建议：
  1. 先在模拟模式测试
  2. 真实机器人周围清空障碍物
  3. 先用 `StandUp` / `StopMove` 测试基础通信
  4. 确认正常后再使用其他动作
