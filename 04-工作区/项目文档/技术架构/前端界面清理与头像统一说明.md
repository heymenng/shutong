## 三、头像统一处理

### 3.1 使用的头像文件

- **源文件**：`本地书童头像.jpg`（25KB，适合 base64 内嵌）
- **备用文件**：`书童头像.jpg`（4.9MB）

### 3.2 头像注入机制

后端 `本地书童界面.py` 的 `_inject_avatar()` 方法会在响应 HTML 时：
1. 读取 `本地书童头像.jpg`
2. 转为 base64 data URL
3. 替换页面中所有默认头像占位
4. 注入全局变量 `window.BOOKBOY_AVATAR` 供 JS 使用

### 3.3 已覆盖的界面

| 界面 | 头像位置 | 状态 |
|---|---|---|
| 师父 PC 端 | 顶部品牌区、聊天消息区 | ✅ 已注入 |
| 家庭端 | 侧边栏品牌区、输入区打字指示、聊天消息 | ✅ 已注入 |
| 手机端 | 登录页、顶部栏 | ✅ 已注入 |
| 墨童 | 顶部品牌区 | ✅ 已注入 |
| 家庭访问入口 | 页面中央大头像 | ✅ 已注入 |

### 3.4 修改的 HTML 文件

为统一头像替换，修改了以下文件中的默认头像占位：
- `墨童.html`：把 `🦞` 改为 `<span class="default-avatar">📜</span>`
- `书童家庭访问入口.html`：把 `📖` 包上 `default-avatar` 类
- `书童手机端.html`：把登录页和顶部栏的 `📖` 包上 `default-avatar` 类

### 3.5 修改的后端逻辑

`本地书童界面.py` 的 `_inject_avatar()` 增强：
- 支持替换 `📜` 和 `📖` 两种默认头像 emoji
- 支持手机端无 `default-avatar` 类的历史结构
- 支持家庭访问入口页的大头像替换

1. 如需更新头像，替换 `本地书童头像.jpg` 后重启服务即可。
