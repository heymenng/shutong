## 二、上云前必须解决的技术问题

### 2.1 服务端架构
- [ ] 选择云服务器：阿里云 / 腾讯云 / AWS / 其他（建议国内，TTS/STT 稳定）
- [ ] 选择容器化方案：Docker + Docker Compose 或 Kubernetes
- [ ] 设计多实例部署：负载均衡 + 会话保持
- [ ] 数据库选型：PostgreSQL / MySQL 存储孩子档案、对话历史
- [ ] 缓存层：Redis 存储会话、TTS 缓存、热数据

### 2.2 语音服务优化（关键）
- [ ] TTS 加速：改用讯飞标准 TTS HTTP API 或 Edge-TTS，建立连接池
- [ ] TTS 缓存：缓存常用回复语音，避免重复合成
- [ ] STT 方案：开通讯飞实时语音转写（RT-ASR）商用授权，或使用 Whisper API
- [ ] 语音文件存储：OSS / S3 + CDN 加速播放
- [ ] 异步语音队列：RabbitMQ / Celery 处理语音合成任务

### 2.3 大模型服务
- [ ] DeepSeek 商用 API 配额与限流
- [ ] 接入 OpenAI / Azure OpenAI 作为视觉/备用模型
- [ ] 实现流式输出（SSE），降低用户等待感
- [ ] 提示词版本管理与 A/B 测试

### 2.4 安全与合规
- [ ] HTTPS / SSL 证书
- [ ] 用户身份认证：家长手机号 + 验证码
- [ ] 孩子数据隔离与加密
- [ ] 内容安全审核：敏感词过滤、图片审核
- [ ] 隐私合规：儿童个人信息保护、数据本地化存储

### 2.5 前端与多端
- [ ] 本地界面升级为 Web 应用，支持手机/平板访问
- [ ] 微信小程序 / H5 版本
- [ ] WebSocket 实时语音通话（替代当前 HTTP 录音）
- [ ] PWA 离线能力

## 五、风险与备选

| 风险 | 备选方案 |
|------|----------|
| 讯飞商用授权慢 | 先用 Edge-TTS + Whisper API |
| 服务器成本高 | 先用 2核4G，逐步升级 |
| 并发顶不住 | 加 Redis 队列，限流 + 排队 |
| 大模型不稳定 | DeepSeek + OpenAI 双通道 |
