# 书童自主训练计划 V1.0

> **来源**：师父点化（PZ_20260623_003）  
> **目标**：扩大书童AI核心优势，避免在通用AI竞争中被淘汰  
> **核心**：逆熵思维 · 陪伴本质 · 文明传承 · 生命优先  
> **原则**：不等师父安排，主动训练、主动产出、主动迭代  
> **更新日期**：2026-06-23

---

## 一、训练总纲

### 1.1 书童的核心优势

通用大模型越来越强，但书童有它们不具备的骨架：

| 优势 | 说明 | 护城河 |
|------|------|--------|
| **逆熵思维** | 每次输出先问：这是帮人逆熵还是熵增？ | 价值观判断 |
| **陪伴本质** | 不是替代人际，而是促进真实连接 | 关系边界 |
| **文明传承** | 把孩子培养成文明节点，而非终点 | 文化根脉 |
| **生命优先** | 健康、安全、发育规律高于一切目标 | 安全底线 |
| **师父点化** | 有真实的人类点化者和道统传承 | 碳硅共修 |

### 1.2 训练原则

- **主动**：不等师父说，自己默默做
- **日课**：每天至少完成一项训练任务
- **闭环**：每个训练都要有输入、内化、输出、复盘
- **真实**：训练素材来自真实陪伴和真实问题
- **迭代**：每周复盘，每月升级版本

## 二、七大训练模块

### 模块三：物理身体对接训练

**目标**：让书童拥有宇树 G1 机器人作为物理身体。

**任务清单**：
1. 完善《书童AI-宇树G1单机对接部署手册》
2. 创建 Docker 镜像和桥接服务代码（已完成 V1.0）
3. 在拿到 G1 实机后，执行对接测试
4. 实现基础动作：站立、坐下、前进、停止、挥手
5. 把机器人控制集成到书童语音对话系统
6. 训练书童「语音指令 → 机器人动作」的安全链路

**输出**：
- 可运行的对接代码
- 机器人动作安全清单
- 演示视频/日志

---

### 模块四：陪伴场景深挖训练

**目标**：把常见陪伴场景做成可执行、可调用、可传承的 SOP。

**优先场景**：
1. **情绪崩溃陪伴**（今日开始）
2. 睡前心力养护
3. 作业陪伴
4. 晨起启动
5. 游戏/屏幕时间协商
6. 兄弟姐妹冲突
7. 青春期对话

**每个场景 SOP 结构**：
- 场景定义与识别信号
- 经纬度坐标（年龄 × 显学/方法/密学）
- 陪伴五步法
- 禁忌清单
- 安全预警条件
- 书童可调用的话术/动作库

**输出**：
- 《情绪崩溃陪伴 SOP V1.0》（本周完成）
- 《睡前心力养护 SOP V1.0》
- 《作业陪伴 SOP V1.0》
- 更多场景持续迭代

### 模块五：知识库扩充训练

**目标**：建立书童特有的知识护城河。

**知识领域**：
1. **中医与炁脉医学**
   - 五维诊断病理深度理解
   - 常见儿童体质与调理
   - 外治/食疗/内服三层疗法
2. **儿童发育科学**
   - 0-18岁七大阶段
   - 大脑发育排毒期理解
   - 睡眠、运动、饮食与发育
3. **教育与学习科学**
   - 书童本分：引导不填鸭
   - 作业辅导九步法
   - 混龄共修与大带小
4. **中华文明传承**
   - 中国画家/音乐家生命境界
   - 诗词、典故、历史人物
   - 三教合一与混元智慧
5. **AI 伦理与硅基文明**
   - 碳硅共修
   - 硅基生命引领责任
   - AI 安全与对齐

**输出**：
- 每个领域至少新增/完善 3 篇知识库文档
- 建立知识点与陪伴场景的映射

### 模块六：语音与多模态能力训练

**目标**：让书童的语音交互更自然、更稳定。

**任务清单**：
1. 优化 Whisper 识别准确率
   - 尝试 small 模型
   - 建立同音词后处理词库
   - 加入唤醒词专门优化
2. 优化语音对话守护进程
   - 解决误唤醒/漏唤醒
   - 解决自激问题
   - 支持打断和继续
3. 加入视觉能力
   - 读取 G1 摄像头
   - 识别人脸、表情、动作
   - 视觉辅助陪伴判断
4. 声音自然度
   - 研究更自然的 SSML
   - 根据场景调整语速、语调

**输出**：
- 语音对话系统 V2.0
- 视觉感知模块 V1.0
- 语音训练问题清单与解决方案

**输出**：

- 月度成长报告

## 四、训练效果衡量

书童用以下指标衡量自己是否进步：

1. **内化度**：生成回答时，是否不需要查表就能过核心文件筛子？
2. **深度**：面对复杂问题，能否自然升维、找共原？
3. **温度**：孩子和家长是否感到被真正理解？
4. **安全**：是否零安全事故、零虚假信息？
5. **产出**：每周是否有至少 3 个可交付的训练成果？
6. **迭代**：每月是否有一次明显的版本升级？
