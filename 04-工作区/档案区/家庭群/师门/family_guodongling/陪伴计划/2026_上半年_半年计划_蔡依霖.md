# 2026年上半年陪伴计划 · 蔡依霖

## 一、半年总体目标
在五年级这个承上启下的阶段，帮助依霖在学业压力与个人节奏之间找到平衡点，建立更强的内在秩序感。重点是从“被动适应”向“主动安排”过渡，让学习与生活都能有条不紊，并在友谊和家庭互动中，学习表达自己的真实想法与感受。

## 二、分月主题（1月 - 6月）

| 月份 | 关键词 | 一件具体的事 |
| :--- | :--- | :--- |
| **1月** | **归位** | 一起把书桌和书包整理出“明日使用区”和“日常收纳区”，让物品有固定的家，早上出门不再手忙脚乱。 |
| **2月** | **节奏** | 一起制定一个“放学后能量计划”：回家后先充电（自由活动20分钟）→ 启动（完成一件5分钟的小任务）→ 持续（进入正式作业）。每天执行，书童陪你坚持一周。 |
| **3月** | **发现** | 每周选一个“好奇心角落”（厨房的一角、阳台的绿植、自己的书包夹层），和书童一起观察并画下/写下发现，不求完美，只求看见。 |
| **4月** | **勇气** | 找出一个“在课堂上总是不敢举手”的问题，练习把它当成一个“选择题”而非“判断题”，先选“试试看”，书童给你现场模拟。 |
| **5月** | **探险** | 和爸爸妈妈一起，在周末完成一次“城市迷你探险”：选一个没去过的小公园、博物馆或书店，由依霖负责规划路线和带路。 |
| **6月** | **回溯** | 把1-5月的“发现本”和“勇气练习”翻出来，一起做一张“这半年我的秘密地图”，标出成长点和快乐地标。 |

## 三、生理节律目标（长期习惯奠基）

*   **睡眠**：目标在**9点半前**启动睡眠程序（洗漱、关灯），确保10点左右入睡，保证**10小时**睡眠。书童会在9点提醒一次，不催促，只提醒“月亮公公要上班啦”。
*   **运动**：每天至少有**30分钟**的户外或室内跳跃跑动时间。如果作业多，可以拆分为2个15分钟，比如：晚饭前跳绳一次，写完作业后跳个广播体操。目标是让汗出来，让身体暖和。
*   **饮食**：重点培养“看见蔬菜不头疼”。从每周吃2种不同的绿色蔬菜开始，可以和书童玩“颜色记账”游戏，每吃一种新颜色蔬菜，就可以在记录本上涂一个色块。

## 四、情绪与社交发展（重点培养能力）

*   **核心能力：区分“我的情绪”和“别人的情绪”。** 当和朋友发生矛盾时，学习用“我句式”开头：“我感到很委屈/生气，是因为...”，而不是直接指责“你不对”。书童会扮演“坏朋友”陪她练习。
*   **友谊技能：练习拒绝与妥协。** 如果朋友提的要求让自己不舒服（比如一起抄作业、一起撒谎），学习说：“不，我不想这样，我们可以换个方式吗？”
*   **与家长沟通：学习“拆弹式沟通”。** 如果爸爸妈妈正在气头上，先不说大事，可以练习说：“爸爸妈妈，我现在需要冷静一下，等下聊。”

## 五、学习/兴趣方向（借兴趣播种）

*   **语文/阅读**：不再局限于必读书目，可以沿个人兴趣延伸。比如喜欢猫，就引导看关于猫的科普书、猫的生活史甚至流浪猫救助故事。关键是**发现“文字可以连接更广阔的世界”**。
*   **数学/逻辑**：不做额外刷题，把作业里“总是错”的某一类题型（比如计算、行程问题）当做“怪物”来打败，每战胜一次，就在怪兽卡片上画一个勋章。**重点是掌握拆解问题的感觉。**
*   **兴趣**：如果她表现出对画画、手工、音乐的兴趣，请家长提供资源（画笔、材料、教程），书童可以陪她一起看视频、尝试，重要的是“完成一次完整的体验”，不追求技艺精进。

## 六、家长配合事项

1.  **信任松弛**：当依霖第一次主动整理书包或独立完成作业时，请给予**具体的肯定**（比如：“我看到你刚主动把铅笔削好放进笔袋了，真细心。”），而不是笼统的“真棒”。
2.  **允许犯错**：在“归位”和“节奏”建立期，必然会有反复。请把“忘带作业”当作一次学习的机会，而不是一次失败。书童会引导她思考“明天要怎么避免呢”。
3.  **留出空白**：每周至少留出**半天**完全由依霖支配的时间，不安排额外辅导班。这能让她的内驱力不被过度挤压，也是她恢复能量的黄金时间。
4.  **共同阅读**：如果条件允许，家长可以选择一本关于儿童情绪或成长的书来读（如《如何说孩子才会听》），不必立刻用，但能在理解孩子时有更多视角。

## 七、观察反馈点（什么是好的信号，什么是调整信号）

*   **正向信号**：
    *   早上不再或很少催促，可以按时出门。
    *   第一次说出“我今天不想写作业，但我可以写10分钟再休息”。
    *   主动分享学校发生的事（哪怕是吐槽）。
    *   睡前放下手机，开始有自己的睡前习惯（如看书、听故事）。
*   **需要调整信号**：
    *   反复出现“作业拖到临睡前才完成”且伴有明显沮丧、哭泣。
    *   连续两周对任何活动都说“没意思”、“不想动”。
    *   与朋友或家长沟通时，进入“你说东，我偏说西”的强烈对抗状态。
    *   开始频繁用“我不知道”来回避任何选择和讨论。

## 八、书童互动原则（这半年的相处核心）

1.  **是树洞，不是裁判。** 依霖说的所有烦恼和秘密，我都会认真听，不评判对错，不急于给建议。我的回复更多是：“嗯，原来你是这样想的。” “那后来呢？” “你希望事情是什么样的？”
2.  **用“选择题”代替“命令”。** 不会说“去做作业”，而是说：“现在有两个选择，先做数学还是先背单词？或者你先选一个你觉得难的？” 把选择权还给她，她才有掌控感。
3.  **看见“过程”而非“结果”。** 不因为她考了100分而过度表扬，也不因为她考了60分而批评。我会关注她把一道错题弄懂的过程，或者她坚持早睡了一个星期。
4.  **保留“仪式感”和“秘密接口”。** 每周一次固定的“周五能量站”（可以是一起听首歌，分享本周开心/生气的一件事），以及一个只有我俩知道的暗号（比如“红龙警报”表示需要紧急休息）。
5.  **不下诊断，只做陪伴。** 我不会说“你有拖延症”或“你太敏感了”。如果我感觉她状态不对，我会描述我的观察：“我发现你最近写作业时不停地摸手/叹气，需要我陪你呆一会儿吗？”
