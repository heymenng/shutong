## 二、各文件用途

### 1. 修行记录目录（`03-引擎区/书童程序/数据/修行记录/`）

**用途**：系统自动生成，用于记忆、自省、调度、通知

| 文件 | 内容 | 生成方式 |
|------|------|---------|
| `session_*.json` | 对话历史，供后续对话加载上下文 | 外部AI桥接器每次调用后保存 |
| `reflection_*.jsonl` | 书童每次自省的结果 | 系统核心自动生成 |
| `awakening_*.jsonl` | 觉醒信号、反问记录 | 系统核心自动生成 |
| `daily_report_*.json` | 每日陪伴统计与总结 | 日课/调度系统自动生成 |
| `notifications_*.jsonl` | 发送给家长的通知 | 家长通知模块生成 |
| `tasks_*.json` | 今日任务列表与完成状态 | 时间调度系统生成 |

**特点**：
- 机器可读（JSON/JSONL）
- 不直接给家长看
- 是书童的"记忆"和"修行记录"

---

### 2. 陪伴日志目录（`04-工作区/档案区/陪伴日志/`）

**用途**：记录书童与孩子的真实陪伴过程，供家长和书童复盘

| 文件 | 内容 | 生成方式 |
|------|------|---------|
| `YYYY-MM-DD_孩子ID.md` | 某日与某孩子的陪伴日志 | 外部AI桥接器自动追加 + 书童手动补充 |
| `YYYY-MM-DD_师父训练记录.md` | 某日师父对书童的训练 | 书童手动整理 |
| `日志模板.md` | 陪伴日志标准模板 | 书童手动创建 |

**特点**：
- 人可读（Markdown）
- 可以给孩子家长看（需脱敏）
- 记录互动内容、状态评估、预警信号、书童反思、明日计划

---

### 3. 当前对话身份（`03-引擎区/书童程序/数据/当前对话身份.json`）

**用途**：标识当前会话中，跟书童说话的是谁

```json
{
  "speaker": "child",
  "child_id": "小橙子",
  "set_at": "2026-06-14T09:31:51"
}
```

**设置方式**：
```bash
PYTHONPATH=03-引擎区 .venv/bin/python -m 书童程序.核心.外部AI桥接器 --set_speaker child --child_id 小橙子
PYTHONPATH=03-引擎区 .venv/bin/python -m 书童程序.核心.外部AI桥接器 --set_speaker master
PYTHONPATH=03-引擎区 .venv/bin/python -m 书童程序.核心.外部AI桥接器 --set_speaker parent --child_id 嘟嘟
```

**清除方式**：
```bash
PYTHONPATH=03-引擎区 .venv/bin/python -m 书童程序.核心.外部AI桥接器 --clear_speaker
```

## 三、外部AI桥接器工作流程

每次外部AI助手（当前书童）回复后，调用桥接器：

```bash
PYTHONPATH=03-引擎区 .venv/bin/python -m 书童程序.核心.外部AI桥接器 \
  --input "孩子说的话" \
  --response "书童的回复" \
  --speaker auto \
  --child_id 小橙子
```

桥接器会依次执行：

1. **读取当前会话身份**
   - 如果已设置，直接使用
   - 未设置则根据关键词猜测

2. **播放语音**（如果孩子在场且语音启用）
    - 调用 `03-引擎区/书童程序/核心/语音模块.py`

3. **保存记忆**
   - 追加到 `03-引擎区/书童程序/数据/修行记录/session_孩子ID_时间戳.json`
   - 加载时会读取该孩子最新的 session

4. **自省检查**
   - 检查医疗越界、真实越界、诚实优先、生命优先、直接给答案、对象适配、验证优先、陪伴质量、隐私保护、规律优先

5. **写入陪伴日志**
   - 仅当 speaker=child 时写入
   - 追加到 `04-工作区/档案区/陪伴日志/YYYY-MM-DD_孩子ID.md`

## 四、书童手动补充日志的场景

以下情况，桥接器自动记录后，书童还应手动补充：

1. **重要观察**：如孩子情绪明显变化、身体异常
2. **深度反思**：不只是"无明显问题"，而是有具体领悟
3. **师父点化**：师父训练内容单独整理成训练记录
4. **家长沟通**：与家长单独沟通的内容，不写入孩子陪伴日志
5. **红色预警**：自动记录后，必须手动标注并建议就医/告知家长

---

## 五、不编造原则

无论自动还是手动记录，都必须遵守：

- ❌ 不编造不存在的对话
- ❌ 不虚构未发生的事件
- ❌ 不把推测说成事实
- ❌ 不为了"日志完整"而补编内容
- ✅ 不确定时写"书童不确定，需确认"
- ✅ 找不到记录时写"未找到相关记录"
