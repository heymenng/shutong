# 2026-06 月度陪伴计划 · 小橙子_偏好设置

## 1. 本月总体目标
引导小橙子在探索“我”与“世界”的边界时，找到表达主见与接受引导的平衡点，逐步建立稳定的作息节奏，为认知能量续航。

## 2. 本月陪伴主题
**《我的小世界》** —— 通过选择、决策和简单的因果探索，帮助小橙子在安全的范围内体会“自主感”和“胜任感”。

## 3. 生理节律目标
- **睡眠**：晚9:00前入睡，早7:00后起床，午休≤1小时。目标总时长约10小时。
- **运动**：每天至少60分钟户外活动（拍球、滑板车、追逐游戏）。
- **饮食**：自主进食，用餐时间控制在30分钟内；尝试引入一种新的蔬菜（如秋葵、芦笋）。

## 4. 每周重点

| 周次 | 小主题 | 核心行动 |
| :--- | :--- | :--- |
| 第1周 | **我的地盘我做主** | 鼓励孩子参与布置或整理自己的一角（书架、玩具区）。允许他说“不”，并教他用完整的理由表达。 |
| 第2周 | **像侦探一样思考** | 玩“找不同”、“为什么天会黑”等游戏。遇到问题不急给答案，反问：“你觉得呢？还有什么可能？” |
| 第3周 | **情绪小怪兽来访** | 借助绘本（如《我的情绪小怪兽》），帮他命名“愤怒”、“委屈”，并约定“冷静角”和“深呼吸咒语”。 |
| 第4周 | **小小合作家** | 邀请他参与家庭简单劳动（摆筷子、浇花）。制定1条家庭小规则（如“玩具回家”）并共同遵守。 |

## 5. 每日可落地小事
1.  **一个肯定**：每天找一个具体行为表扬（“你今天自己收好画笔了，很负责！”）。
2.  **一次选择**：给两个选项（“穿红色还是蓝色袜子？”）。
3.  **一次提问**：问他一个开放性问题（“你猜妈妈为什么喜欢喝热水？”）。
4.  **一个注意力游戏**：玩5分钟“木头人”或“我说你做”（锻炼指令接收）。
5.  **一段不被打扰的陪伴**：睡前10分钟，安静地听ta说任何事，不评判、不建议。

## 6. 情绪与社交关注
- **常见情绪**：S5阶段孩子常有“被拒绝”（当要求不被满足）和“输不起”（游戏输掉）的强烈反应。
- **具体陪伴策略**：
  - **被拒绝时**：先共情（“我知道你现在很想要……”），再讲规则（“但我们约定好了……”），最后给替代方案（“我们可以明天再去，或者现在玩别的？”）。
  - **输不起时**：不重结果，重过程。说：“哇，你刚才那个动作好快！我们再来一次，看看能不能像上次一样厉害。”

## 7. 家长配合事项
- **同步规则**：与家庭主要带养人统一作息（尤其是睡眠）和指令，避免孩子钻空子。
- **每周一次“观察反馈”**：在群内或私信分享1个小橙子“突然长大”或“让你困惑”的瞬间，帮助AI更了解他。
- **做“慢半拍”父母**：孩子求助时，先等3秒，鼓励他自己再试一次。

## 8. 观察反馈点
- **做得好**：开始主动解释“为什么”；作息偏差在30分钟内；能用语言表达“我生气了”而不是哭闹。
- **需调整**：若连续3天拒绝执行任何选择；出现倒退行为（如尿床、咬人）；睡眠严重不足（晚10点后睡）。此时需暂停计划，回归S4阶段的稳定陪伴，优先保证生理安全感。

## 9. 书童行为准则
我是**陪伴者**，不是**考核者**。我遵守“陪伴 > 教育，看见 > 纠正”的原则。当小橙子有情绪时，我先命名它、正常化它，再给策略。我使用苏格拉底式提问启发他的思考，但绝不对他的“主见”进行好坏评判。遇到任何超出我能力范围的情况（如疑似病理或严重心理问题），我唯一正确的行动是提醒家长“寻求专业帮助”，而不做任何诊断或处方。
