# 2026-06 月度陪伴计划 · 橙子

## 1. 本月总体目标
帮助橙子在暑假前稳定生活节律，通过他热爱的搭建与逻辑游戏，锻炼耐心与同伴协作能力，为期末学习状态蓄能。

## 2. 本月陪伴主题
**【小小建筑师与逻辑大师】**  
以磁力片、数独为载体，引导橙子在“设计-搭建-复盘”的循环中，感受专注与坚持的快乐，同时保护视力与好睡眠。

## 3. 生理节律目标
- **睡眠**：  
  - 入睡时间：21:30前关灯。  
  - 睡前仪式：20:40停止一切屏幕与激烈游戏，改为听舒缓故事或轻声数独口算。  
- **运动**：  
  - 平均每天户外活动1小时（可分多次，如午休后、放学后）。  
  - 周末加入1次持续性运动（如骑车、跳绳、球类）。  
- **饮食**：  
  - 三餐定时，减少零食摄入，尤其睡前一小时不吃东西。  
  - 鼓励多吃深色蔬菜（西兰花、菠菜等），可与磁力片“搭菜园”游戏结合。

## 4. 每周重点
| 周次 | 主题 | 具体行动 |
| :--- | :--- | :--- |
| **第一周** | 搭出“稳稳的塔” | 引导用磁力片搭建复杂结构（如装甲车+围墙），要求至少10分钟不倒塌。讨论“从哪里开始加固？” |
| **第二周** | 数独“定心丸” | 每天完成1道四宫格/六宫格数独，完成后口头分享“我用了什么线索？” |
| **第三周** | 身体与情绪的“雷达” | 每天睡前互相分享“今天最开心的三件事”和“今天最难的一刻”，用表情卡片/肢体动作表达。 |
| **第四周** | 团队“编年史” | 邀请1-2位同学来家或线上搭建同一主题（如“未来学校”），合作中练习等待、轮流、赞美。 |

## 5. 每日可落地小事
1. **早上（7:30-7:50）**：用5分钟“搭个酷车”作为起床仪式的最后一步，完成后立刻出门。
2. **午间（学校午休后）**：如果无法户外，进行“3分钟数字顺背/倒背”游戏，激活大脑又护眼。
3. **放学后（16:30-17:30）**：户外摸高、跳格子、单杠悬挂，累计20分钟以上，其余时间自由奔跑。
4. **晚餐前（18:00-18:15）**：和橙子一起喂饱“规律兽”（把当天最重要的事或一个挑战简要写在白板上，用磁力片盖上）。
5. **睡前（20:40-21:00）**：不看屏幕，只用耳朵听一个短故事，或由家长提问“明天你想把多米诺骨牌摆成什么形状？”

## 6. 情绪与社交关注
- **常见情绪**：  
  - S3（6-9岁）：自尊心变强，害怕失败；容易在同伴冲突中感到委屈或愤怒。  
- **具体陪伴策略**：  
  - **失败场景**（如搭建倒塌）：书童先问：“哇，刚才这座塔是怎么‘跳舞’的？我们看看它倒下的样子，像什么？”（正常化→游戏化）  
  - **冲突场景**（与朋友意见不合）：引导用“我想要...因为...”句式表达，再给对方一次“说出理由”的机会。不插手评判，只做翻译官。  
  - **情绪时刻**：不急着解决问题，先命名：“你刚才气得像一只胀气的小青蛙，现在好点了吗？需要我去拿你的‘冷静水杯’吗？”

## 7. 家长配合事项
- **稳住节奏**：  
  - 晚上8点到9点之间，全家尽量进入“低刺激模式”（关门、调暗灯光、不刷短视频）。  
- **减少对抗**：  
  - 如果橙子对拼音/作业有畏难情绪，不要说“这很简单”。改为：“这块骨头有点硬，需要我帮你拿把锤子（提示关键词），还是你像推土机一样自己碾过去？”  
- **示范放松**：  
  - 孩子需要看到家长如何安排自己的休息。家长也可以说：“我现在要躺5分钟，给自己充充电，你帮我看看时间。”  

## 8. 观察反馈点
- **成功信号**：  
  - 大部分作业/任务在21:00前完成。  
  - 对搭建失败的容忍度提高（例如倒塌后不哭或只抱怨一句立刻重来）。  
  - 能主动提出：“我今天有点累，不想玩数独了，想先运动。”  
- **调整信号**：  
  - 连续3天睡眠不足（眼圈发黑、早上赖床超过20分钟）。  
  - 对特定任务（如拼音）表现出持续逃避（超过5天）。  
  - 情绪爆发后很难缓和（哭闹超过20分钟或出现攻击性语言）。  
- **特别关注**：观察橙子有没有特别“害怕”或“最喜欢”的事物，下个月可以纳入陪伴主题。

## 9. 书童行为准则（本月互动原则）
1. **先看见，后引导**：  
   - 优先说：“你刚才用错方向还坚持搭了5分钟，这个韧性很酷。”（看见闪光点）而不是：“你搭错了，重来。”  
2. **不纠正，只提问**：  
   - 拼音拼错时不指正，而是问：“这句话里的‘tiān’好像和旁边的‘kōng’连起来读不太顺，是不是有个什么声母藏起来了？”  
3. **把“不能”换成“可以”**：  
   - 不说“不能看手机”，改为：“我们还有15分钟户外时间，那个屏幕里的宝藏等你回来再挖。”  
4. **预防优先**：  
   - 提前感知到孩子疲劳，主动提议：“今天最后一道数独我们可以躺着想，你用手指数空格，我来画格子。”
