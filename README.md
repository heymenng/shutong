# 伴读书童AI · 家庭版

> 运行在您本地电脑上的智慧家庭助手。
> 云端长智慧，本地记亲情。

## 项目结构（九区制）

```
shutong/
├── 00-灵魂区/          # 道统核心、AGENTS.md、WORKFLOW.md、项目档案总览
├── 01-配置区/          # 启动脚本、config.json、安装说明、依赖清单
├── 02-知识库区/        # 中华文明、世界文明、发育科学、中医基础、话术库、训练素材
├── 03-引擎区/          # 书童 Python 程序、本地数据、static 资源
├── 04-工作区/          # 家庭档案、项目文档、运行日志、云端数据区
├── 05-交付区/          # 安装包、入口链接、测试报告、纪要
├── 06-对接区/          # 本地 Web 服务、前端页面、vendor、cloud_server.py
├── 07-工具区/          # 工具脚本、构建脚本、检查脚本
└── 08-归档区/          # 历史归档、旧版本备份
```

完整结构说明见 [`00-灵魂区/项目档案总览.md`](00-灵魂区/项目档案总览.md)。

## 快速启动

### Mac

```bash
cd /Users/lingjue/Documents/shutong   # 或您的实际项目路径
.venv/bin/python 01-配置区/start.py
```

或双击运行：

```
01-配置区/启动书童.command
```

### Windows

```bash
.venv\Scripts\python 01-配置区\start.py
```

## 配置

首次使用前，请在 `01-配置区/config.json` 中填入：

- `cloud_api_base`：云端服务地址（默认 `https://bookkidai.com`）
- `family_id`：您的家庭 ID
- `api_key`：您的订阅密钥

详见 [`01-配置区/README_安装说明.md`](01-配置区/README_安装说明.md)。

## 重要边界

- **灵魂文件**（AGENTS.md、WORKFLOW.md、核心提示词、训练素材）只存云端/开发仓库，不进家庭安装包。
- **家庭隐私数据**全部保存在本地 `04-工作区/档案区/`。
- 没有联网时，书童是一个本地空壳；联网并校验 `api_key` 后，才具备完整灵魂。

详见 [`00-灵魂区/云端与本地边界说明.md`](00-灵魂区/云端与本地边界说明.md)。
